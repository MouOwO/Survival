# 云组件第二版

本次只改云。已确认的模型、地面材质及主地图保持原样；新云采用 `_v2` 资源名，上一版可继续对比。

## 修改

- 厚云：使用非等距、不同体量的主体与次级云体，平滑融合体积密度，再以多个尺度的噪声扰动边界；增加高低起伏。
- 云带：用连续、局部破碎的密度场替换旧的正弦细管，让云带有宽窄和厚薄变化。
- 光照：使用上方暖色主光与冷色填充，保留云底明暗；并未使用泛光。
- 每张云为独立 Blender 体积场，烘焙为 2048 × 1536 RGBA。引擎文件补透明边至 2048 × 2048，不拉伸。

## 验证与复现

`alpha_validation.json` 检查原始 PNG 的透明边框、可见范围和半透明像素；`mip_validation.json` 检查 2048 至 256 尺寸的缩小边界。深浅色与棋盘背景预览在 `index.html` 中。

生成脚本：`tools/xianxia_cloud_revision.py`（Blender，HIP，正式版 256 samples）。预览与检查：`tools/xianxia_cloud_review.cjs`。引擎资源准备：`tools/xianxia_cloud_stage.cjs`。安装及编译：`tools/install_xianxia_cloud_revision.ps1`。

组件测试地图沿用相同镜头、四个粒子的平面位置和已有场景。首次实机检查发现旧位置低于水面，导致云底被截平，因此最终版另提高了云的 Z 高度，使透明轮廓完整露出。安装脚本确认实际地图包已重新写入，避免测试窗口锁住旧包后误判。

## 使用范围

这仍是固定俯视角、烘焙光照的透明云片，尚非运行时体积云。建议少量放在岸外、崖脚与非活动区域，保持通道和平台清楚可见。近距离旋转、过度放大及大量重叠仍会暴露平面和透明排序问题。边缘技术检查通过不代表整图云海构图已完成；本次不自动铺满主地图。
