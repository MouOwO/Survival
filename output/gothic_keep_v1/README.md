# 哥特风主城 V1

- 主文件：gothic_keep_v1.blend；场景 Gothic Keep Preview。
- 模型交换文件：gothic_keep_v1.glb（仅建筑，不包含摄影棚）。
- 预览：gothic_keep_preview.png。
- 比例依据：buildings_config.lua 主城占地 2×2，grid_placement_config.lua 每格 64。底座 128×128，高度约 189，Z 向上、门朝 -Y、原点在底座中心地面。
- 风格：四角八角塔、中央钟楼、尖拱门窗、玫瑰窗、蓝黑屋顶、铜金饰边、红色旗帜。
- 当前为造型与材质原型；尚未制作烘焙贴图、LOD、碰撞体或 Source 2 编译资源，未替换游戏现有主城。
- 生成脚本：../../tools/build_gothic_keep.py。通过 Blender MCP 在独立场景创建，原场景保留。
