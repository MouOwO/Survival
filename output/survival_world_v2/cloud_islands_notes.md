# 独立云岛修订

本轮将闲置山地从实际地形网格中移除，保留活动平台、模式内道路、水域和中央四座三层主岛。上、下练功房的高度关系保持原样；温泉与少量亭阁保留独立装饰岛。

- 切除 25,216 个原山地网格，旧山地树海收缩为装饰岛上的局部植被。
- 外围恢复包围式云海，采用宽度、位置和高度错开的云层。
- 岛间云带使用水平云片，放在最低活动平台下方；底层为无碰撞的青灰色大气背景，避免岛间出现纯黑空洞。
- 平台新增侧壁仅保留 220 单位厚度。中央主岛的城门层、防御塔层和楼梯结构保留。
- 小型草地练功房及普通 Boss 房去除碎绿贴块，改为连续浅暖灰铺地；大场地草地、冰雪和火山主题保留。

第一轮实机中，上一版 Blender 云片仍呈现模糊椭圆，已从本轮地图的云带中替换为 Valve Crownfall 云纹理。使用两种轮廓、透明混合及不同朝向组合，不再使用旧的小球散布发射器。

素材限制：当前仍是云片模拟，原生云纹理为 1024 像素，带固定明暗和细碎颗粒；近距离放大、低角度观察不等同于体积云。进一步达到效果图质量需要高分辨率、柔和边缘、统一清晨受光的多视角云素材或可实时受光的云壳。本轮不通过继续密集复制来弥补这些限制。

实际检查结果和截图时间见 `verification.json`。本轮修改前的地图、脚本和图片保存在 `before_separate_cloud_islands`。
