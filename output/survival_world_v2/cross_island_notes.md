# 四向主岛与原生纹理遮罩

本次按四个凹形岛缺口朝内的参考拼图调整主岛。修改前的地图包、截图和生成脚本在 `before_cross_islands`；原项目 `template_map.vmap` 只读。

`tools/world_v2_original_island.cjs` 从原项目可编辑地形提取高度、水域、道路边、材质绘制、植被、道具与变化编号，旋转后移植进同一张 128 × 128 网格。四岛交汇处按对角线分配地形，避免重叠地形产生闪烁。中央十字水道使用连续底面和浅水材质。外围功能区继续沿用上一版布局。中央海域与相邻水域统一基准高度，并接齐不足一个地形格的细缝，避免人工矩形岸线。

官方依据是本地 Dota 原生 `materials/blends/mod_radiant_dire_000.vmat_c`。反编译结果在 `output/reference_asset_study/official_border_decompiled`：使用 `multiblend.vfx`，启用 `F_NORMAL_MAP`、`F_TINT_MASK`，第 1、2、3 层分别指定碎土、草和岩石的 `TextureRevealMask`，并带有 `dota.tile_transition_material=1`。这些遮罩使草叶、碎石等沿纹理形状交错，而非一条均匀透明带。

本项目五种地面材质改用原生草、碎石、积雪、玄武岩、熔岩与石板的揭露遮罩；顶点混合软度调整为 0.16 / 0.20 / 0.14，保留较宽的宏观过渡带，同时增加细碎的边缘形状。纹理直接提取自现有资源，没有新绘制贴图。房间下方统一使用连续的原生地形底层；各环境由上层遮罩材质与对应树木、岩石表达，避免原生雪地/秋土地形块在表面网格之外露出白色或黄色直边。

构建：准备材质和无荷叶地形模板 → 生成地图 → 几何检查 → 同步 content 目录 → 编译材质 → 编译地图 → 实机验证和截图。实机结果以本次更新的 `verification.json` 与截图清单为准。

实机验收：132 个导航采样通过，其中 50 个检查十字浅水道；横纵穿行及四营地到中央的寻路全部通过。底面实测 396，顶部/下方练功房高差保留。9 张截图均晚于当前地图与材质编译时间，未发现缺失的项目材质，也没有编译进荷叶模型。
