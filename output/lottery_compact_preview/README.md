## 运行时九宫格与详情切池隔离

本轮纠正上一轮“预先拼接九宫格后仍整图缩放”的实现：`LotteryNineSlice` 由三行九个 Image 构成，四角32设计单位，边条只沿各自方向延展，中心填充；外层仍只进行一次等比适配。九个分片均已编译。透明截图外沿通过轮廓蒙版裁去；透明分片只绘制一次，避免背景与Image重叠加深边缘。浏览器验证面板1045×760和1200×850时角块均32×32；原生缩放与边缘最终观感待游戏内核对。

详情弹窗拥有独立 detailPoolId/detailState。快照请求携带 scope 与递增请求编号，服务端路由仅回传这两个UI关联字段，不改变抽奖业务。详情切池不再更改主界面标题、选中、余额或实际抽奖pool_id；关闭后迟到响应被丢弃。回归覆盖主界面地图池、详情暑期池、关闭后继续抽地图池。

已直接检查 v2 zip：没有独立页签高亮图片或高亮 SVG。原图高亮由 `pool_details_reference.png` 的本地1045尺寸参考裁取，在裁切脚本里提取金色亮线、菱形并透明化背景，上部过渡由裁取像素延展。它不是压缩包提供的独立完成素材，也不宣称完整逐像素还原。
