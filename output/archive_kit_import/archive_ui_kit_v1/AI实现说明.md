# 存档弹窗 · 共用 UI 组件交付 V1

请将本包和 reference/progress_mockup.png 一起交给开发 AI。本包是素材与实施规格，尚未修改游戏代码。原图背景保留为视觉参考；实际游戏露出实时地图，不把示例地图截图盖在游戏上。

## 可直接发给 AI 的任务

请在现有 Dota 2 项目中实现存档弹窗，保留当前存档业务数据和解锁规则。先检查项目真实 UI 技术和现有组件，再实现。以 reference/progress_mockup.png 为布局依据，以本包纹理、图标为资源依据。禁止自行替换成旧图标、Unicode 符号或系统 emoji。不要把整张效果图当背景后再叠一层文字。

1. 弹窗外是全屏黑色蒙层，初始透明度 55%；蒙层点击关闭、右上角 X 关闭；弹窗内部点击不能触发关闭。展示真实游戏地图。弹窗不全屏。
2. 左侧共用 NavToggle 组件，参数为 id、label、icon、selected、disabled。全部分类共用一套布局和纹理，不能逐个复制硬编码页面。选中使用玉白底、深青文字和深青图标，未选中使用青蓝底、浅金图标与浅色文字，悬停适度提亮。单组选中唯一。选中与悬停分开处理，移出鼠标不能丢失选中状态。
3. 右侧使用 ArchiveCard 网格，每卡由底板、图案、名称、右上角 ProgressBadge、底部解锁状态独立组成。当前视口四列三行，多余条目纵向滚动。不要恢复右侧常驻详情面板。
4. 右上角进度使用动态文字 current/required，例如 3/10、10/10；required 来自实际配置，不写死为 10，不从示意图读取游戏数据。没有进度字段的卡片隐藏角标。解锁状态由真实业务字段决定，不随意假设计数达标后自动领取。名称和数字都不能烘焙到图片里。
5. 解锁条件和存档效果只放到悬停 tooltip 中，从现有数据绑定。tooltip 出现在卡片附近，遇屏幕边缘自动避让，不能导致卡片重排；不要把“待接入”文字作为正式文案。
6. 建立统一 IconButton、NavToggle、ArchiveCard、ProgressBadge、FilterTab、ModalShell、Tooltip 组件和资源映射。按钮图标与背景、文字解耦，未来抽奖/背包等页面复用同一组件和状态规则。
7. 标题采用思源宋体 Bold，正文、数字与按钮使用思源黑体 Medium/Regular；这是建议的落地字体，不声称生成图里存在可提取的同名字库。本包不含字体，使用项目已授权字体文件并检查中文覆盖。
8. 设计坐标基准 1672×941。弹窗主体参考 x335 y90 w1002 h758；左栏宽240，内容区约762。网格左上约(605,320)，单元约162×154，横向步长174、纵向步长164。先在基准尺寸匹配，再由父容器统一等比缩放并居中。不同元素不要各自按屏宽屏高拉伸。纹理像素尺寸不是最终显示尺寸，不要直接把所有素材按原生像素放到屏幕上。
9. reusable 中新补绘的按钮/卡片是无文字组件，材质接近参考，但装饰不是原图逐像素一致。优先组合这些干净组件；exact_crops 只用作比对，不可将带原文的裁片当通用按钮。先提交游戏截图与参考图叠加比对，检查弹窗比例、网格密度、字体、图标、状态和进度位置，再推广到其他页面。
10. PNG 透明资源四周不可填黑，禁止将灰底组件总览当透明资源。检查深色和浅色背景上的边缘。所有状态使用同一显示框、中心点和图标尺寸，切换状态不能抖动。按钮 hover 约100ms颜色渐变即可，不要大幅缩放。

## 文件使用边界

|目录|内容|使用方式|
|---|---|---|
|reference|原图、进度效果图、补绘空白组件总览、空白弹窗参考|只作设计参考|
|exact_crops|41 张原始像素裁片，包含已烘焙文字或背景|核对位置和质感；不能冒充分层资源|
|icons_rgba|12 种小图标，各4种颜色状态，共48张64×64透明 PNG|从合成图提取轮廓并重新着色，非原始矢量；建议约32–40设计像素显示|
|art_tiles|12 张卡片图案裁片|保留玉白底纹，无透明背景；在玉白卡片内部使用|
|reusable|12 张无文字透明底板：toggle3、button3、card3、badge3|同风格新补绘后去背景，非原图直接裁片|
|background_tiles|底纹小块、卡框9块及空白弹窗主体|细分边框参考；小纹理不保证无缝平铺|
|manifest.json|每份裁片尺寸、坐标和来源类别|供 AI 自动查找资源；不可猜测裁切区域|

透明小图标 normal/hover/selected/disabled 为共用颜色状态。导航图标映射：clear=通关存档，void=虚空之影，points=积分道具，weapon=神兵碎片，spell=秘法牢笼，endless=无尽存档，friends=我的好基友，ex=我的前女友，blessing=瑞兽赐福。close=关闭，book=存档标题书本，hint=详情提示。

## 状态资源规则

- NavToggle：normal/hover/selected 三张底板；disabled 使用 normal 降低透明度，禁用点击。按下可用 hover 降低亮度，无需新造纹理。selected+hover 保持 selected 底板只轻微提亮。
- IconButton：四态图标保持同样 64×64 画布。图标视觉尺寸由组件控制，透明留白不应被自动裁掉。
- ArchiveCard：normal/hover/selected 底板；locked/unlocked 是业务状态，独立于鼠标状态。锁定卡仍可悬停看条件，不等于 disabled。
- ProgressBadge：深青胶囊，数字层居中，右上内缩约6设计像素；显示尺寸建议52×22。示意角标为圆角胶囊，本包装饰底板稍有差别，可优先用项目圆角背景精确匹配示意。
- Button：normal/hover/pressed；禁用由 normal 减淡并阻止点击。

## 关于背景与还原程度

空白弹窗由原图编辑补绘，细节存在生成差异，不能宣称逐像素恢复了被卡片遮挡的区域。shell_body.png 为 x335,y90 起的1002×758矩形主体裁片，保留青色标题栏、侧栏、玉白面板，未包含上方突出的标题冠饰。需要冠饰时另行组合原图标题装饰或补绘；不要从包含地图背景的参考图直接覆盖实时地图。

卡片图案是原图带底纹裁切，透明图标是估算提取；缺少原始 PSD/分层文件，因此本包不宣称全部资产无损分层。已提供可复用底板与真实 alpha 图标，实施时先在真实画面验收边缘与文字。数值、名称、图案绑定均以现有游戏配置为准。
