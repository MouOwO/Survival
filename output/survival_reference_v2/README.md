# 苟发育地图地形首版

地图：survival_reference_v2。按用户参考截图的区域关系生成，可在 Dota 2 Tools 中预览。

包括 N1–60 模式区域、转生 Boss 岛、十诫岛、材料怪区域、七宗罪、16 个普通练功房、4 个年轮练功房，以及原创挑战预留区。非水域、非功能区的原黑色空地生成山体，另用导航阻挡保证不可通行。

最终编译后实机抽样 97 点，失败 0，见 verification.txt。该检查验证点位地面高度和通行标记，不代表全部路径和玩法验证。

本版用于确认布局与比例。山体仍为粗模，水面为简单蓝色材质，整体光照偏暗，部分原生混合贴图显示效果需要后续调整。出生与挑战点已标记，但各模式传送、刷怪和奖励逻辑尚未全部接入。

源文件：survival_reference_v2.vmap；布局数据：layout.json；布局示意：layout.svg；实机截图：ingame_overview.png。
