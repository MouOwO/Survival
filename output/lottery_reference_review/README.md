## 实现及缩放

Panorama 详情面板固定 1045×600，内部明确坐标与尺寸，不再采用 fill-parent-flow 分配卡片或详情栏宽度。列表固定322高，第三排位于裁剪区域外，底栏单独固定。四个页签按参考占左侧792宽，不均分整条1003宽。其他信息弹窗维持现有行为。

项目现有 combat_stats.js 使用 `actuallayoutwidth / actualuiscale_x` 将屏幕像素转换为逻辑单位；本轮沿用这一坐标惯例。只读取外层遮罩的尺寸及原生 UI 比例，计算一个等比系数 `min(logicalWidth*0.682/1045, logicalHeight*0.69/600)`，仅设置面板外层 `scale3d(s,s,1)`。内部不再乘屏幕比例，避免重复缩放。模拟测试验证1920×1080、原生比例1与1280×720、原生比例2/3产生同一逻辑缩放系数。

固定底板 `pool_fixed.svg` 没有文字，按设计尺寸绘制。边框不单独伸缩，整面板统一缩放，因此本轮没有将边角非等比拉伸，也无需额外的可变尺寸九宫格。若以后要独立改变面板长宽，应另做边框分片，不能重新拉伸此固定底板。

## 明确差异，不用错误素材补偿

1. 原包 pool_panel.png 带大幅风景，与参考详情底板不一致，本页已停止使用。新固定底板只近似参考边框和纯色分区，尚缺精确的细纹理及角花；不是逐像素美术复刻。
2. v2 提供的 pool/close 图标和简化按钮轮廓与生成参考图的装饰不同，继续按用户之前的 v2 SVG 优先规则使用，没有为追逐效果图换回旧图标。
3. 奖品继续使用真实物品美术。截图中的黑色矩形部分是 Dota 物品原图背景，不是功能 SVG 的透明边缘；不能统一扣黑破坏图像。原生物品图保持88:64比例。
4. 指定思源字体未安装/注册。实际浏览器字体为 SimSun、Microsoft YaHei；没有宣称已加载思源或已排除原生字体黑方块。功能图标不使用字体符号，没有新增黑圆点占位。
5. 参考概率和奖品均为占位，实际页面显示真实数据、隐藏未知概率。没有复制“待接入”概率，也没有改变发奖/消耗。标题名称采用项目配置；占位图和真实图之间的像素差异不算结构误差。
