## D 键迁移

每次按 D 或点击迁移技能都启动新的建造网格会话，使用当前塔的模型预览、占地和同一格中心。服务器再次检查所属玩家、存活、技能冷却、1000 距离及地块占用；超距拒绝，不把落点悄悄截短。右键、Esc、换选和过期回复均有取消或隔离路径。普通塔与 UR 共用校验，沿用各自的正式迁移实现。

2026-10-01 响应修正：左键直接提交当时的格中心，不依赖模型预览完成或旧绿色回复；服务器只对迁移开放首次直接提交，并重新执行校验。若配置尚未返回，保留首次点击坐标，配置就绪后执行一次。提交途中不重复请求模型；落点拒绝后开启新会话，可直接换格重试。提交前右键/Esc/换选会取消尚未发送的意图；已被服务器接受的迁移不提供撤销。

新版编译后的真实经济建造塔已完成一次快速 D：物理 D 按下至左键按下间隔 32.63 ms，实体 647 从 `(256,4736,385.5)` 到 `(704,4736,385.5)`，仍是同一塔并正常进入冷却，N 标签位于新位置。此间隔不是移动延迟或渲染帧时间；当时配置是否已缓存未确定。其余协议与边界组合的模拟证据见 [输入验证](ai/validation/20261001/tower_relocation_input.json)。

随后已实测占用落点拒绝、保持网格并直接左键换格重试。最终第二冷局再次验证正常建造塔626：D至左键间隔32.94 ms，一次点击完成同一段迁移，服务器预览ghost=0、激光fixture已清理。这里验证的是正常塔迁移，不将其扩大为正在攻击的神秘塔迁移全流程验收。

## 2026-10-01 战斗表现与开销修正

激光的 CP9/CP0 绑定塔攻击挂点，CP1 绑定目标命中挂点，由引擎跟随；没有可用挂点时沿用配置高度回退。绑定成功的端点不再被服务器位置快照覆盖。过期光段、换目标、死亡和普通塔 D 清理改为立即销毁，避免已释放句柄的原生淡出尾段留在旧位置。0.12 秒视觉重播的浮点误差也已修正；0.03 秒观察、每秒伤害及同目标伤害递增保持。自动验证覆盖挂点/回退、移动、换目标、D 清理、死亡、API 失败和伤害时序。

最新移动目标实机使用官方远程单位完成原生攻击初始化，再套用生产 Storm 外观、神秘塔数据、激光与寻敌模块，移除 `modifier_creep_piercing`。四塔在31秒状态中各有31次激光计数、目标生命减少71021，移动目标各转向44次、行进7970单位，每塔两段光束的两端均保持实体绑定。生命减少包含普通攻击，不用于推导激光单独数值。此前 NO_ATTACK 展示壳无法开始原生攻击，相关无伤害样本不作验收依据；没有因此修改生产寻敌行为。移动跟随与测试壳验证见 [激光记录](ai/validation/20261001/laser_follow_validation.json)。

已归档并检查[横移位置 A](../art/effects/review/20261001/laser_four_follow_a.png)与[横移位置 B](../art/effects/review/20261001/laser_four_follow_b.png)，两图都能看到四束激光随目标位置变化；这是两个静态时刻的证据，不代表连续视频的逐帧检查。

塔顶 UI 仍逐帧读取世界位置与高度，只对零塔、全屏遮挡提前返回，并避免重复写入相同样式。使用同一实际 JS 的 40 塔×300 帧模拟：静止可见的样式写入从 24000 降至 0，投影调用仍为 24000；全屏遮挡后实体调用和投影调用为 0，遮挡首次出现仍立即隐藏已有行。没有修改共用遮挡模块或降低跟随频率。记录见 [UI 验证](ai/validation/20261001/tower_rank_performance.json)。

## 第一版表现

- N 不加常驻底座，使用参考明文配置中可核实的原生远程弹道。
- 转职后按七类职业配置底座；SR/SSR 增加符纹或流光，红星与 UR 使用第三层。移动保持已有粒子句柄，死亡、拆除、替换和换局清理。

- 陨石改为原生 Rubick 至宝的棱角方块，组合暖色飞焰、落地冲击和熔岩。原有 0.8 秒落地、伤害半径、持续伤害及末阶双陨石时序保持。
