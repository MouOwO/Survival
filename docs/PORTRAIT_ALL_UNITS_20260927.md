# 全部单位头像底色、建筑取景和玩家栏（2026-09-27）

## 修改

- 将当前配置使用的 165 种模型纳入底色覆盖，生成 661 个模型色映射；覆盖英雄、工人、建筑、普通怪物、挑战怪物及 Boss。扫描模型配置后没有缺失映射或通用蓝灰兜底。建筑按木材、石材、铜金等主材质区分柔和底色。
- 选中单位与常规英雄快照都提供实际 GetModelName，解决共用单位名称但动态更换模型的怪物串色。独立英雄头像仍优先采用其实际显示的英雄色；跨实体快照不能影响当前颜色。

- 左上角原生玩家栏按 RadiantPlayer/DirePlayer 的玩家 ID，从 survival_hero_skills 获取各自召唤英雄，替换 HeroImage.heroname。保留原生点击和玩家槽位。没有召唤英雄时恢复原占位图，选中敌人/建筑不会使头像跟随改变。
