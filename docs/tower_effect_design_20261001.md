# 防御塔特效搭配方案｜2026-10-01

> 最新试玩版：[三套同英雄升阶皮肤与底座](tower_effect_design_20261002.md)，当前默认 A。以下保留早期设计记录。

> 后续进度：第一版已接入，实际测试请看[第一版测试对照表](tower_effect_trial_1_20261001.md)。下面保留原方案阶段记录。

**建议先选 A 套：轮廓清晰、命中有力、各路线容易辨认。** B 套更偏魔幻，可以局部替换。直接回复“全部 A”，或“死亡 B、冰塔 B，其余 A”即可。

本次是设计与资源核对，**没有修改当前游戏配置**。“保留”来自现有代码；“候选”已经在本机找到资源文件，但尚未接入或实机验收。以下颜色、尺寸、节奏是设计目标，不代表已经看到候选的最终渲染效果。

## 1. 整体风格

按照你之前的反馈，采用这些规则：

- **冲击感来自弹头、短尾迹、命中爆点。** 激光用向目标前进的亮点和目标表面火花，不用大面积光幕。
- **R、SR、SSR 换整套攻击表现；同阶 1–5 级保持同一套。** 等级只小幅增加核心宽度、碎屑数量；红星延续 SSR。
- **每座塔只保留一套底座。** 新底座接入时，旧图片、纹样、冠层一起退场。新底座可以有配套子粒子，但不能两套底座叠加。
- 底座贴地、低亮，塔顶不放遮住角色或敌人的大光球、大光幕。充能用少量上升亮点。
- 职业色：死亡紫／魂火，激光蓝白→红，雷电白蓝，机枪琥珀，弩炮木色→猩红→橙火，冰塔冰蓝，防空青蓝。**不把所有 SSR 都染成金色。**
- 只换美术，不增加英雄原技能的眩晕、弹射、减甲或伤害。攻击间隔、命中时刻、范围和数值保留，不能为了看清弹道直接降低真实弹速。

已经确认的设计优先保留：修补匠分阶激光、SSR 原生雷电、萨尔不朽 R 风暴、娜迦网、幻刺暴击血、飞龙 R 与飘雪、裂魂人／圣堂／拉席克底座、终极塔斯拉克黑气。

## 2. A 套：推荐搭配

“命中”指视觉反馈，不增加伤害范围。底座另列在下一张表。

| 路线 | R 1–5 | SR 1–5 | SSR 1–5 |
|---|---|---|---|
| **死亡之塔 → 碎骨重炮 → 死神榴弹炮** | **候选：影魔原生普攻。** 紧凑魂弹、短尾迹、小命中火花 | **候选：冥魂大帝冥火爆击飞行骷髅。** 骨炮有实体弹头，命中碎裂；不挂眩晕 | **候选：影魔至宝普攻＋配套命中。** 魂火弹核、短促扩散；重击才放大爆点 |
| **神秘之塔 → 魔能炮 → 魔能之眼** | **保留：修补匠默认 Q。** 蓝白核心，随级变粗 | **保留：现有 TI10 不朽 Q 蓝白适配。** 区分光束结构和外缘颗粒，不提前变红 | **保留：现有不朽神掌／神杖版本。** 红色粗核心与少量命中喷溅，不恢复光幕 |
| **闪电塔 → 闪电魔塔 → 雷电扩散** | **保留：宙斯原生 Q** | **保留：风暴之示 Q。** 现有 TI8 不朽电弧 | **保留原生 Q，候选增强命中短闪。** 只在真实扩散触发时出电圈，不换回细金雷 |
| **机枪塔 → 赏金机枪 → 爆矢加特林** | **候选：狙击手原生普攻。** 白金短曳光 | **候选：狙击手 Witch Hunter 普攻。** 当前工程已有素材调整至 SR，配短促碎屑火花 | **候选：矮人直升机原生普攻。** 更厚短炮弹、短炮口火，取消风行长飘带 |
| **多重塔 → 穿透弩炮 → 炙热巨箭塔** | **候选：米拉娜原生普攻。** 多支可辨认的箭 | **保留：玛尔斯猩红始祖之祸 Q 现有弩炮适配。** 长矛轮廓、猩红尾迹 | **候选：克林克兹灼热之箭直线弹体。** 替换穿透技能的复仇之魂波，普攻配同系灼热箭，命中散少量余烬 |
| **冰霜之塔 → 寒冰尖塔 → 极地方尖碑** | **保留：巫妖原生连环霜冻。** 小冰球、短冰尾 | **候选：巫妖 TI8 不朽连环霜冻。** 冰晶球＋配套碎冰命中 | **候选：TI8 冰球加强版。** 增加稀疏冰片与碎裂爆点，不扩大冰雾；这是自定义组合，不冒称第三款不朽 |
| **防空塔 → 防空火炮 → 空域霸主** | **候选：矮人直升机原生普攻。** 紧凑高射炮弹，朝空中目标发射 | **候选：发条照明火箭弹体。** 做追踪火箭，命中轻烟火花；需适配跟踪与朝向 | **保留：天怒法师至宝普攻。** 青蓝能量弹，不附加神秘之耀大光柱 |

两处有意不强求三套不同主资源：雷电 SSR 尊重你“换回原生”的决定；冰塔 A 延续你“用巫妖连环霜冻”的决定。通过命中和辅粒子区分阶段。**冰塔若一定要三个不同主弹体，选冰塔 B。**

### A 套底座与技能

| 路线 | 唯一常驻底座 | 技能搭配与分阶变化 |
|---|---|---|
| 死亡 | **候选：戴泽 Weave 圆形描边子粒子。** 紫色低矮细圈，需常驻适配，不铺暗雾 | 保留幻刺暴击飙血，仅真实暴击触发；碎骨重击加短亮闪，死神追加伤害对应第二个短爆点。底座 R 细圈、SR 少量流动光点、SSR 稀疏魂火点 |
| 神秘 | **保留拉席克 W 地面脉冲现有适配** | 连续激光保留；魔能炮增益用少量充能粒子；魔能之眼仅在实际受伤目标上出溅射。高阶底座更清楚，不加第二圈和塔顶幕布 |
| 雷电 | **候选：萨尔动能力场“形成标记”层。** 取贴地标记并常驻适配，不使用竖直电墙 | 保留风暴串联之震 R；扩散保留现有剃刀电圈，匹配实际范围。底座从稀疏电点到环边短电弧；普攻不额外生成整场风暴 |
| 机枪 | **保留裂魂人 W 脚下特效** | 赏金反馈集中在触发位置；加特林增速期间强化炮口火，不让每发都炸一团大火。三阶调整底座细节密度，不铺持续燃烧区域 |
| 弩炮 | **候选：克林克兹骷髅大军地面旋纹＋少量余烬子层。** 不调用召唤物和烟幕 | SR 猩红矛，SSR 灼热穿透箭。底座 R 低亮旋纹、SR 少量猩红余烬、SSR 橙色余烬；改色和常驻循环需验证 |
| 冰塔 | **候选统一用冰魂 Ice Vortex 贴地旋涡** | 保留飞龙 R 地面冰霜＋飘雪，范围不变。底座由薄冰旋纹升级到稀疏冰晶；删除旧图片底座，并合并当前 SSR 已有旋涡，避免双播 |
| 防空 | **保留圣堂灵能陷阱双环** | 保留娜迦网，仅原有概率触发时罩住目标，不恢复眩晕标记。SR／SSR 增加少量环内光点，不长出光柱 |

### 终极之塔

终极塔独立处理，不套 R／SR／SSR。**保留斯拉克 R 周身黑气**，以角色轮廓附近的烟流为主。

- **A：保留当前终极底座作为唯一底座，压低亮度。** 攻击沿用实际继承技能，不额外同时发七种装饰弹。
- **B：底座换戴泽紫色细环，配斯拉克黑气。** 旧终极底座层全部退场，走暗紫风格，不使用谜团黑洞式黑幕。

## 5. 接入后的逐项验收

建议顺序：**机枪 → 冰塔 → 弩炮 → 防空 → 死亡 → 雷电 → 激光 → 终极。** 每条路线先一座，再四座，不要先满屏混测。

| 场景 | 通过标准 |
|---|---|
| R／SR／SSR 各打高血量目标 | 不看名字也能辨认阶段，不靠满屏发亮来升级 |
| 连续攻击密集怪群 | 怪物轮廓、血条、飞行方向和命中点都清楚 |
| 秒杀小怪 | 仍有一次发射和命中；死亡前保存世界坐标，残留不依赖已销毁的目标附件 |
| 激光击杀后换目标 | 旧效果短暂结束、新目标及时建立；不重新连续挥手，不出现双光幕 |
| 四座同时攻击 | 不过曝、不叠底座；与当前同场景对比帧耗后决定密度 |
| 升级、搬动、移除塔 | 底座正确跟随、清理，没有旧圈、残火和悬空弹头 |
| 伤害日志与血条对比 | 每次结算的时间、数值、死亡时刻均与旧版一致；死亡时血条归零，不剩约 30% 突然消失 |

命中残留建议从 **0.15–0.30 秒**起试，箭尾更短。这是调参起点，不是已验证的最佳值。死亡残留只保留视觉，不延迟真实死亡，不继续伤害。

不能假定“预计 5 秒死亡”始终准确：转火、暴击、其他塔伤害会改变死亡时刻。血条应跟随实际结算并在死亡时归零，不用虚构血量配合动画。

## 6. 资源核对与实施注意

核对依据：当前七条塔 CSV、激光与雷电效果表、底座配置、特殊技能代码、本机 Dota 原生 VPK，以及你给的守望轮回谷资源包：

```text
D:\SteamLibrary\steamapps\workshop\content\570\3164617180\3164617180.vpk
```

其中发现 `particles/rebuild/spell/tinker_1/big_laser/effect/tinker_laser.vpcf_c` 等大激光素材，可参考辅粒子结构。文件存在不等于适合整套搬入；要先检查是否包含你不喜欢的光幕，再取需要的亮点层。

1. 冰塔当前各阶都是巫妖连环霜冻，CSV 弹速为 `100000`。“一闪就没”可能与飞行时间很短有关。保持真实结算，另行评估短尾迹和命中残留。
2. 炙热巨箭的线性穿透弹由技能代码单独创建，目前是复仇之魂至宝恐怖波动。**普通攻击弹道与技能弹体要一起核对**，不能只改 CSV。
