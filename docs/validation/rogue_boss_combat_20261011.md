# Boss 战斗卡逐卡审计（2026-10-11）

> **当前结果：** [48张启用卡的最新实际Dota自测](rogue_card_native_selftest_20261011.md)及[机器结果](../../validation/20261011/rogue_card_native_selftest.json)。本文件保留早期审计记录；其中“尚未游戏内验证”等历史状态以最新报告为准。

审计对象为 17 张启用的 Boss 战斗卡。核对来源包括 `data/csv/肉鸽奖励系统/rogue_reward_{cards,effects,effect_params,effect_lifecycle}.csv`、对应生成 Lua，以及实际领取运行时、建筑事件、Modifier、护甲换算和伤害过滤器。以下“通过”指离线执行生产 Lua 消费者；没有把模拟实体测试称为 Dota 客户端实战验证。

## 本轮已修复

1. 火药溅射原先按每座塔的阶段向玩家级缓存写入 0 或 30，炮塔串联再读取该残值，会把弩炮加成传给其他塔。现在弩炮资格与数值保存在对应塔实体，串联只共享领取时的固定快照，两种领取顺序均得到相同结果。
2. 火药溅射缺少 `building_created` / `building_changed` 生命周期。已有 handler 虽有刷新函数，事件不会调用。现补齐创建、升级和转职刷新，进入穿透弩炮阶段获得加成，离开该阶段移除它。
3. 炮塔串联把无来源的 `max_level` / `survival_tower_max_level` 回退为 5，所有已转职塔都被误计为最终满阶塔。现通过真实路线最后一行判定满阶；领取结果保存后不随新增、升级或销毁重新计数。
4. 串联原先是已完成的即时事务，后续塔没有刷新入口。现在以持续投影保留领取快照，后续塔继承相同固定加成；上限仍是 50%。
5. 落井下石原先只识别统一 Buff，漏掉生产使用的冰霜塔、暴风雪专用减速 Modifier。现在两类减速也触发 50% 增伤；多种减速不会重复增伤，攻速减慢不会被误当作移动减速。
6. 腐蚀护盾直接向护甲消费者传 1，消费者再将 Dota 护甲转换成游戏显示护甲，实际每次降低 3 点。现在先把 CSV 的 1 点游戏护甲换算为运行时的 1/3 点，实际护甲连续从 100 降到 99、98。
7. 虚弱宝珠没有检查出怪事件的玩家通道，其他玩家先生成的 Boss / 精英会消费持卡者效果。现在只有相同玩家的正式波次匹配角色可以消费，仍只作用一次。
8. 铁腕政策原先只识别原生普通攻击，漏掉以脚本交付的机枪、多重箭和激光攻击。现在仅对匹配来源类型的可信攻击标签接入护甲忽略，普通塔及终极塔均覆盖；原生攻击缩放判定保持独立，物理法术、未知脚本标签和魔法伤害不放宽。
9. 渴血药剂调用回血前接入英雄生命保护器的 `allow_healing`，避免合法吸满血被属性刷新后的延迟保护回滚；本回归直接安排保护器延迟任务后执行生产吸血 callback，确认回血保留。渴血与装备吸血共用 `combat/lifesteal_amount`，把目标的实际伤害按目标/自身生命投影比例换算为自身原生回血量，避免大额怪物生命压缩导致吸血丢失或重复恢复攻击缩放。
10. 步调一致原先只读英雄逻辑快照，没有纳入斗志昂扬、训练和装备的真实附加攻击。现在优先读取关联召唤英雄的 `GetAverageTrueAttackDamage`，恢复英雄攻击投影并除以接收塔的攻击投影；句柄不可用、getter 抛错或数值无效时回退逻辑快照。
11. 训练靶子永久成长原先直接作为原生攻击量，英雄大额攻击投影后会重复放大。现在仍保存 100 点逻辑成长，原生 getter 按当前攻击投影换算；后续投影变化不更改已存成长。装备附加攻击使用相同单位边界，并向客户端发送原生数值。
12. 弩炮/串联刷新原先每次建筑变更都销毁重建 Modifier。现在同值跳过、变化刷新原 Modifier，归零时移除效果并清理缓存；同值科技刷新不会反复重建效果。
13. 终极融合塔原先没有持续消费防御工事、斗志昂扬、串联和步调一致。现在专用服务与独立 Modifier 接入创建/科技/英雄路径，保持融合素材已烘焙的攻击收益，以创建时基线接入后续增量，不改终极塔业务身份。

## 已识别但未在此补丁扩大的语义范围

- **额外攻击与百分比。** 新兵作训、炮塔成长、火药溅射、炮塔串联和斗志昂扬使用 `MODIFIER_PROPERTY_BASEDAMAGEOUTGOING_PERCENTAGE`。来自步调一致、靶子、英雄装备等 `PREATTACK_BONUS_DAMAGE` 的攻击没有同时按该百分比增加。比如基础 100、额外 100，再领取基础百分比 +30%，当前总攻击为 230；如果卡面要求总攻击整体 +30%，应为 260。把属性改成最终伤害倍率会同时影响伤害过滤、技能伤害和多段攻击，不能无回归地替换。
- **终极合成塔继承。** 合成塔仍以 `survival_ultimate_tower` 独立标记，刻意不设 `survival_building_id`。专用服务补接攻速、斗志、串联与步调；已经烘焙的七素材攻击贡献保留，创建时这些效果的新增量为 0。后领百分比按究极塔自身的继承攻击增加百分点，英雄变化按新增一座塔的一份步调投影差计算，不追溯拆解七份素材贡献。新兵/弩炮的阶段资格仍限定普通塔；其材料收益可以被融合继承。直接购买的终极塔没有真实素材，基线为 0，已有全塔效果只应用一次。
- **怪物范围。** 冰封城墙、落井下石、腐蚀护盾既有消费者覆盖正式波次怪与建筑挑战怪，三张卡面现已明确该范围。转生等独立 encounter 使用自己的标记及奖励链；没有扩大敌人标记并顺带改变树、英雄执行等其他消费者。
- **升级生命周期。** 防御塔 `max` 一次跨多级发布一个完成事件，炮塔成长按一次升级动作增加一个 10% stack；转职单独发布 `tower_class_changed`，不属于该升级生命周期。科技刷新、失败/取消或其他玩家事件不增加成长。
- **脚本交付的普通攻击。** 保留 `is_basic_attack` 的原生缩放保护，另以 `tower_machine_gun_attack/script`、`tower_laser_attack/script`、`tower_multi_arrow/splash` 三组来源进行护甲忽略。回归执行真实机枪 hit handler、DamageService、transaction repository、Dota adapter 和 filter，确认脚本已经是逻辑伤害，不能再次乘攻击投影 scale。
- **靶子同名类。** `modifier_rogue_training_dummy` 在注册表和两个模块中有重复定义。最后的注册与生成 binding 指向 `modifier_rogue_combat_effects`，本回归使用该实际最终定义；旧独立模块带下一波/墙死亡提前移除和不同成长 Modifier。应后续清理为单一定义，避免热加载顺序改变其行为。
