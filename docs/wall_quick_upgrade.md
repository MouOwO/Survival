# 城墙升级按钮

- 1-1 城墙显示普通升级和“城墙直升9-1”两个技能。
- 普通升级完成一次后，直升技能隐藏；失败或取消仍可使用。
- 直升目标为建筑配置第 25 级（9-1），从 `building_levels.csv` 第 2～25 级逐行累计升级费用，当前合计木材 946600、金币 143860，不重复收取建造费用。
- 直升需要支付累计费用，不消耗或套用肉鸽的一次免费普通升级权益。服务端检查当前等级、主城条件、余额和正在升级状态；取消或启动失败返还已扣资源。
- 到达第 30 级（10-3）后普通升级按钮也隐藏。建筑创建、状态恢复和升级完成均同步技能可见性。

新增原生技能需要完整重开测试局加载 NPC 配置。
