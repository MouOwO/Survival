# 伐木攻击间歇卡顿：重复属性刷新修复（2026-09-26）

状态：代码修改和离线回归完成；未采集修复前后Workshop实机帧时间，不能据此宣称全部卡顿已消失。

## 定位

`worker_system.on_tree_hit` 在伐木工具有攻击成长时，每次命中都会请求 `TECHNOLOGY_STATS_GROWTH_ADD_REQUEST`。旧实现将局部攻击成长广播成无范围的 `TECHNOLOGY_STATS_CHANGED`，触发以下无关工作：建筑系统扫描全场并重新应用建筑属性、英雄重算装备与战斗属性、金矿重发状态并调度生产。工人系统也逐个重设没有变化的攻击间隔、射程、采集与暴击等参数。游戏信息及调试面板每次成长都重新生成并写NetTable。

最初怀疑选中生产面板逐次全量推送；继续追踪发现其底层已有0.15秒合并器，因此未改动生产面板及资源结算。现有采集音效也有限流，未改动音效/粒子。

## 修复

- 成长事件增加 `changed_section` / `changed_field`；普通科技和全量事件保持原路径。
- 伐木工成长不会再驱动无关建筑、英雄和金矿属性刷新。
- 工人攻击成长仍同步逐次应用，仅重算攻击力；保留合体倍率、性格加成、所属玩家隔离及选中单位属性事件。
- 游戏信息和战斗调试的成长展示按玩家合并到0.1秒，发送时读取最新状态；重新初始化会取消旧回调。
- 树木满级回血、同一实体且效率不变时，不重复遍历工人修改目标和采集效率；更换树木和等级提升仍更新。
