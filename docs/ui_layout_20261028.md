## 根因与最小修复

`panorama/src/scripts/custom_game/production_progress.js` 的 `PanelGeometry` 在选择 `left`／`above` 位置时，先按完整研究面板宽度判断左侧空间，进入某一分支后才将主城训练面板缩成 75%。实际能放下的训练板因此错误进入上方分支。上方分支继续为 `-126 * g.scale` 的 debuff 行预留空间，放大了队列与技能条之间的距离。

修复先将训练 75% 缩放计入实际占用，再判断左右空间，删除分支中的重复缩放。完整研究面板保持原有缩放与位置选择；技能条、标题、buff／debuff 共享锚点保持原值。主城生命条显示规则、技能条最小宽度和玩法数据均未修改。
