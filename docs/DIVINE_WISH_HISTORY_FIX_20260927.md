# 神许愿宝物记录修复（2026-09-27）

用户反馈：选择“神许愿”后，宝物面板只显示神许愿，没有随机获得的三件宝物。

## 根因与修复

实机只读检查确认，当前对局已经成功发放炮塔成长、火药溅射、实习证明；效果运行时分别保留两个 active 和一个 completed 实例。`grant_random_cards` 原先仅设置 claimed 和 transaction.completed，没有写入用于宝物面板的 state.history；只有手动 select_card 才写入历史。

统一历史写入函数，随机子卡成功后也记录名称、图标、说明、grant_id 和 parent_card_id，并发布 NetTable。完成标记保护重试不重复发放或记账；部分子卡失败时同步已成功的子卡，后续可继续原事务。保持最近 20 条容量与玩家隔离。
