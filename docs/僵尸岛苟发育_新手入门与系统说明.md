# 僵尸岛苟发育：新手入门与系统说明

整理日期：2026年10月2日。

这份说明给刚加入的玩家和项目成员看。用简单的话，先教你玩一局，再说明各个系统。

内容根据当前项目配置、代码和已有说明整理。游戏还在更新，费用、按钮和奖励以后可能变化。文中的“建议”是学习方法，不是保证通关的固定打法；本次没有进入游戏实测整套流程。

## 1. 先看这一页，就能知道大概怎么玩

**一句话：让工人赚钱，用钱建塔守住城墙，再让英雄变强，打完怪物和挑战。**

你主要做这五件事：

1. 建城墙和主城，建立自己的基地。
2. 训练伐木工，让他们砍资源树，获得木材。
3. 建塔、升塔、修墙，挡住一波一波的怪。
4. 召唤英雄，用装备、练功房和转职挑战提高实力。
5. 通关和领取奖励，积累以后的成长。

记住一个顺序：

> 先有收入 → 再补防守 → 解锁英雄 → 打挑战 → 积累存档。

但墙快被打破时，马上修墙、补塔。不要继续把钱全花在赚钱上。

### 几个词是什么意思

| 游戏里的词 | 简单解释 |
| --- | --- |
| 发育 | 赚钱、升级，让自己越来越强 |
| 波次 | 一批怪物；下一波就是下一批 |
| 人口 | 工人、部分建筑和转职塔要占用的名额 |
| 科技 | 花资源学习的升级项目 |
| 全属性 | 力量、敏捷、智力一起增加 |
| 转职／转生 | 完成条件后，进入下一阶段；塔和英雄各有自己的规则 |
| 肉鸽奖励／天赋 | 系统给几个随机选项，你选一个 |
| 存档 | 账号保存的成长和物品；其中哪些能带进下一局，要看模式和说明 |
| Boss | 比普通怪更强的敌人，也叫首领 |
| Lv／LV | 等级，例如 LV3 就是3级 |
| N1、N2 | 难度编号；这里的 N 和物品稀有度 N 是两回事 |

## 2. 第一局照着做

### 第一步：选择模式和难度

开局先等待加载完成。多人游戏由房主选择本局模式和难度。

| 模式 | 意思 | 新手怎么选 |
| --- | --- | --- |
| 常规模式 | 读取账号已有的永久档案加成 | 想正常体验成长，可以选这个 |
| 纯净模式 | 开局不带以前的战斗加成，保留难度解锁资格 | 想了解基础玩法，可以选这个 |

纯净模式仍会按规则结算奖励和消耗。它不是把账号存档删除，也不是完全不保存奖励。

**建议第一局选 N1。** 新账号可以选择 N1～N5，但可以选不代表适合直接打高难度。

通关 N5 后开放 N6，再按顺序通关开放后续难度，最高 N10。解锁需要通关记录保存成功。当前 N6～N10 沿用 N5 的测试战斗配置，不能把它们理解为已经完成数值平衡的五档新难度。

### 第二步：选开局天赋，建城墙和主城

1. 选中建造师，查看开局天赋入口。当前固定快捷键是 **G**。
2. 天赋是三选一，有1次免费重抽机会。读清楚增加什么，再选。
3. 先建城墙。当前建造链一开始只开放城墙。
4. 城墙完成后，建造按钮会变成主城。
5. 主城完成后，才会逐步开放塔、研究所、农场等建筑。

建造师负责建东西，后面召唤的战斗英雄负责打怪。它们是两个不同单位。

### 第三步：开始赚钱，同时准备防守

1. 选中主城，训练低级伐木工。
2. 选中工人，对资源树下达攻击／砍树命令。看木材是否持续增加，别让工人闲着。
3. 建箭塔，让怪物靠近城墙时处于塔的射程内。
4. 查看城墙的血量；按压力升级城墙、训练修理工。
5. 人口不足时，建人口农场并使用人口升级项目。

**第一波目前在确认难度后150秒出现，也就是2分30秒；后续波次间隔目前是90秒。** 这是准备时间，不要一直停在面板里看说明。

建议第一局先学会“工人持续赚钱、塔能打到怪、城墙有人修”。不要一开始追求最贵的建筑。

### 第四步：升级主城，解锁更多玩法

| 进度 | 主要解锁内容 |
| --- | --- |
| 城墙完成 | 可以建主城 |
| 主城1级 | 箭塔、人口农场、普通研究所 |
| 普通研究所完成 | 可以建独立的挑战建筑 |
| 主城3级 | 金矿、英雄祭坛 |
| 召唤英雄完成 | 解锁局内商店 |
| 主城4级，且普通研究所完成 | 可以建高级研究所 |

按钮灰了，先看它写的条件。通常是主城等级、资源、人口、前置建筑或数量上限不满足。

### 第五步：召唤英雄，慢慢打挑战

1. 主城到3级后建英雄祭坛。
2. 打开祭坛选择英雄。每位玩家本局只能召唤1个正式英雄，选择前先看技能。
3. 召唤后打开商店，先认识装备、挑战、转职三个入口。
4. 防线稳定后，再让英雄去练功房和打转职挑战。
5. 出门期间也要看城墙血量和怪物数量。

当前普通英雄包括末日使者、光之守卫、斧王、黑暗游侠；齐天大圣、剑圣有额外权限条件，以祭坛提示为准。

### 第六步：清完正式波次，处理存档挑战和结算

正式波次当前到第30波。终波出怪完成并清完剩余正式波次敌人后，进入通关处理。

当前配置从 N1 就开放通关后的存档挑战阶段。出现挑战入口时，看奖励和条件，选择自己能打的内容。准备结束时，使用“结束存档挑战”；多人需要所有玩家结束才完成本局胜利结算。未击败的挑战 Boss 不给奖励。

结算和领取时看成功提示。不要把“点过按钮”当成“奖励已经保存”。

## 3. 资源和建筑：每个东西有什么用

### 木材、金币、人口

| 资源 | 主要用途 | 主要来源举例 |
| --- | --- | --- |
| 木材 | 训练工人、建造、升级、部分挑战 | 伐木工砍树、木材练功房、奖励 |
| 金币 | 部分高级训练、装备、科技和挑战 | 金矿、金币练功房、奖励 |
| 人口上限 | 容纳更多工人、金矿和转职塔等 | 人口农场的升级项目、部分奖励 |

人口不是钱。钱够、人口不够，也可能不能训练或建造。

### 建筑一览

| 建筑 | 作用 | 第一局要注意什么 |
| --- | --- | --- |
| 城墙 | 挡住进攻，是防线核心 | 已完工城墙被打毁会触发本人失败 |
| 主城 | 训练工人，解锁后续建筑 | 想解锁更多玩法，需要升级它 |
| 箭塔 | 自动攻击敌人 | 摆在能覆盖城墙附近敌人的位置 |
| 人口农场 | 提高人口上限 | 建好后还要查看人口升级项目 |
| 普通研究所 | 研究科技 | 按自己缺什么来学 |
| 高级研究所 | 更高级的科技入口 | 主城4级并完成普通研究所后可建 |
| 金矿 | 持续生产金币 | 主城3级解锁，当前最多5座，每座占2人口 |
| 英雄祭坛 | 召唤战斗英雄 | 主城3级解锁，每人本局只能选1个英雄 |
| 挑战建筑 | 主动召唤挑战敌人 | 有战斗压力时，先别增加敌人 |

多人时，各人的建造、资源、波次和城墙目标按玩家分别管理。不能因为是同队，就默认能操作别人的单位。

## 4. 工人系统：让收入不停

### 普通伐木工

当前有 LV1～LV8。不同等级的费用、主城条件、人口和收益不同。

主城面板会显示尚未达到训练上限的等级，按顺序展示前四项。低级训练达到累计上限后，会补上后面的等级。训练入口变化是正常现象。

伐木工训练可以排队：**1个正在训练，6个等待，合计7个任务**。排队就会预留资源和人口。当前每个伐木工训练耗时1秒。

建议先观察：新工人有没有去砍树？收入增加后，升级和训练有没有明显变快？

### 超级伐木工

用多个同等级普通工人，加上资源，合成一个超级工人。

例如：主城4级时，5个 LV1 普通伐木工加10000木材，可以融合成超级伐木工 LV1。它继承材料工人的当前攻击力之和，攻击间隔减少0.5秒。部分等级还会获得随机性格技能。

这属于后续学习内容。第一次先看融合按钮需要什么，别为了融合把防守用的钱全部花掉。

### 修理工

自动修复受损城墙，要处于有效修理范围内，也会占人口。发现墙持续掉血时，确认修理工存在、位置合适，并补充塔的输出。

修理只帮助墙撑更久。如果杀怪速度一直不够，仍然需要提高防御塔和英雄实力。

## 5. 防御塔系统：先看射程，再看升级

普通箭塔达到5级后可以选择转职方向。当前有七条路线：

| 路线 | 新手先看什么 |
| --- | --- |
| 死亡之塔 | 看暴击和后续炮塔技能说明 |
| 神秘之塔 | 看当前技能的伤害方式和触发条件 |
| 闪电塔 | 看闪电技能能打哪些目标 |
| 机枪塔 | 看连发和攻击速度 |
| 多重塔 | 看一次攻击能覆盖多少目标 |
| 冰霜之塔 | 看减速和范围技能 |
| 防空塔 | **只攻击飞行单位**，不要用它承担地面防守 |

箭塔5级只是进入转职选择，不代表已经到顶。转职后还有后续升级和进阶。

当前普通未转职箭塔最多同时存在7座，转职后释放普通箭塔名额。转职塔会占人口，首次转职当前占1人口，后续升级不会每级再多占1人口。

塔只能攻击射程内的合法目标。目前自动索敌优先打离本人的城墙最近的敌人，但射程外的敌人仍然打不到。

N、R、SR、SSR、UR 是稀有度标记。星级、等级和稀有度要一起看，具体效果以技能说明为准。

### 后期的“七塔合一”

需要本人七条路线各一座符合条件的终阶塔。材料塔保留，但每座永久只能参与一次；生成有七条独立攻击流的无敌终极塔，每位玩家最多拥有5座。

这是后期目标。第一局先掌握普通升级和一次转职。

## 6. 科技系统：缺什么，就研究什么

科技可以帮助经济、防守和英雄成长。读说明时，先找“影响谁”和“增加什么”。

| 当前情况 | 学习方向建议 |
| --- | --- |
| 木材增长慢 | 查看伐木相关科技 |
| 金币不够 | 查看金矿相关科技 |
| 城墙掉血太快 | 查看城墙相关科技，同时检查修理和输出 |
| 怪越积越多 | 查看塔的攻击、攻速等科技 |
| 英雄打挑战太慢 | 查看英雄相关科技和装备 |

操作方法：

- 左键点击科技，加入研究队列。合计7项：1项研究中，6项等待。
- 连续点击同一科技，可以排后续等级。
- 当前每项研究2秒。
- 等待任务轮到开始时才扣费。资源或前置不够，会卡在队首；后面的项目不会越过它。
- 右键科技可以开关自动研究。手动队列优先，自动研究会等待资源和条件。

新手先手动研究一项，确认效果，再尝试自动研究。避免多个自动项目争用你准备修墙或升塔的钱。

## 7. 英雄、装备和挑战：让英雄逐步变强

### 英雄的成长来源

英雄可以通过练功房、装备、转职挑战、技能选择以及相关科技和奖励提高实力。

不要直接套用普通 Dota 的打法。本项目有自己的属性、装备和技能规则。

### 局内商店

召唤英雄后开放，主要分为五类：

| 分类 | 作用 |
| --- | --- |
| 武器与装备 | 提高英雄战斗能力 |
| 道具与材料 | 消耗品、增益和合成材料 |
| 科技与服务 | 相关升级与服务 |
| 挑战商店 | 练功房、材料 Boss 等 |
| 转职挑战 | 按顺序进行英雄转职／转生 |

买装备前看三个问题：谁能用？怎么升级？需要什么材料？

不同装备成长方式不同。有的重复购买升级，有的需要材料合成，有的看普通攻击次数或击杀数。不要以为所有装备都能靠重复购买升满。

### 三种常用练功房

| 练功房 | 当前配置的主要奖励 |
| --- | --- |
| 木材练功房 | 每击杀一个怪，获得100木材 |
| 金币练功房 | 每击杀一个怪，获得100金币 |
| 属性练功房 | 每击杀一个怪，获得100点全属性 |
| 大属性练功房 | 每击杀一个怪，获得1000点全属性 |

奖励高不代表现在就打得动。进入需要资源，敌人也有强弱。建议先从能稳定击杀的练功房开始。

### 英雄转职／转生

当前有1转到10转，要按顺序挑战，不能直接跳到后面。

- 1转：获得英雄专属技能、属性和攻击成长等奖励。
- 2～5转：包括公共技能三选一及其他成长。
- 6～10转：包括公共技能点和进一步成长。

开始挑战不等于完成转职。击败对应敌人并完成奖励处理后，才算成功。

### 材料与建筑挑战

商店还有合成宝石、冰霜、熔火核心等挑战，用于获取对应装备材料。先看自己要升级哪件装备，再找材料来源。

独立挑战建筑可以召唤山岭巨人、树人、红龙、剑圣、炼金等敌人。它的挑战进度独立于正式波次。建议一次尝试一种，确认打得过再增加挑战。

## 8. 天赋、钓鱼、存档和抽奖

### 天赋：给你一个成长方向

开局天赋和正式 Boss 奖励使用相关选择规则。每次出现选项，都先看受益对象：工人、城墙、塔，还是英雄？

建议优先选择当前用得上的效果。例如正在缺收入，就先认真看经济效果，不必只看颜色和名字。

### 钓鱼：按时间获得奖励

项目中的钓鱼包含时间奖励机制。局内钓鱼目前从首次成功确认难度开始计时，奖励间隔为480秒，也就是8分钟。

奖励可能增加当局资源、人口、墙体能力，也可能关联玩家长期成长。**看清“本局效果”和“永久效果”，并以领取成功提示为准。** 不是所有钓鱼奖励都能带到下一局。

### 存档：了解自己长期积累了什么

存档面板包含通关存档、地图等级、Boss存档、神兵碎片、秘法牢笼、虚空之影、钓鱼存档、存档建筑等内容，还有“我的好基友”“我的前女友”“瑞兽赐福”等收集分类。

这些名称是不同成长和收集入口。先看来源、效果、数量、升级条件，再决定是否投入材料。

例如，当前地图等级每提高1级，会增加城墙初始生命100、每秒回血5；常规模式与纯净模式对历史战斗加成的读取不同。

存档挑战部分材料有每日上限。达到上限后，重复挑战不一定还能继续获得材料。

### 每日奖励

存档界面有每日奖励入口。查看当天能领取的内容和条件即可。部分通行证内容仍有未开放配置，不能把面板里的展示都当成已经能购买。

### 抽奖

抽奖使用对应奖券，与局内木材、金币不同。地图奖池当前单抽消耗1张，直接十连消耗10张；直接十连有至少SR的保底，连续做十次单抽不触发这个保底。

特殊奖池仍有待确认配置。具体奖品、概率和保底看当前面板说明。第一局先了解入口，掌握基础防守后再研究收集。

局内装备商店和账号相关商城用途不同。永久道具是否生效、特殊英雄是否可用，都要看账号权限和本局模式。

## 9. 最常见的问题

| 遇到的问题 | 先检查什么 |
| --- | --- |
| 建筑按钮不见了 | 建造阶段变了，或已经达到数量上限 |
| 按钮灰了 | 主城等级、前置建筑、资源、人口、权限 |
| 钱够但训练不了 | 人口、累计训练上限、队列是否已满 |
| 科技排队不动 | 队首是否缺资源或前置条件 |
| 工人不赚钱 | 有没有攻击资源树，是否正在移动或闲着 |
| 塔不打怪 | 怪是否在射程内；防空塔不能打地面怪 |
| 墙一直掉血 | 修理工是否在范围内，杀怪速度是否不足 |
| 英雄出门后基地危险 | 用 F2 回家，同时检查城墙、塔和积怪 |
| 商店没开放 | 是否已经完成正式英雄召唤 |
| 领取后没看到加成 | 奖励对象、本局／永久范围、模式、保存提示 |

### 三个常用快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 | 选中本人的建造师，并移动镜头 |
| F1 | 选中本人的正式英雄；存活时定位镜头 |
| F2 | 让存活的正式英雄回到本人主城旁的安全位置 |

没有召唤英雄、英雄阵亡、缺少有效主城或回程冷却时，回家操作可能不可用。聊天输入和弹窗也会阻止部分快捷操作。

### 两种危险都要看

1. **城墙血量：** 已完工城墙被打毁会导致本人失败。
2. **怪物数量：** 积怪超过允许上限会触发倒计时，未及时处理也会导致本人失败。

多人中一位玩家失败，不代表其他人一定立刻结束。每个人都要看自己的状态。

## 10. 三局学习安排

这是建议的学习顺序，不要求你三局就全部通关。

| 对局 | 学习目标 | 做到什么算学会 |
| --- | --- | --- |
| 第一局 | 建造、伐木、人口、守墙 | 工人能持续赚钱，塔能打怪，知道什么时候修墙 |
| 第二局 | 科技、塔转职、英雄、练功房 | 会研究一个科技，完成一次塔转职，会让英雄出门并回家 |
| 第三局 | 装备成长、英雄转职、存档 | 能说清一件装备怎么升级、一种材料哪里获得、一项奖励是否永久 |

每局结束只想三个问题：

- 我最缺的是木材、金币、人口，还是伤害？
- 哪一步让我防线变危险？
- 下一局先改哪一件事？

不要一次改所有做法。一次改一件，才容易知道有没有用。

## 11. 给新加入项目的成员：怎么快速认识整个游戏

如果你加入的是制作团队，建议先按前面的流程玩一局，再看下面这张表。先懂玩家在做什么，再看实现。

| 系统 | 玩家做什么 | 主要资料位置 |
| --- | --- | --- |
| 开局 | 选模式和难度 | `docs/MATCH_SETUP_AND_MODES.md` |
| 建筑与工人 | 建基地、伐木、修墙、研究 | `data/csv/建筑与工人系统/`、`docs/BUILDING_PRODUCTION.md` |
| 防御塔 | 升级、转职、合一 | `data/csv/建筑与工人系统/防御塔/` |
| 英雄 | 召唤、选技能、培养 | `data/csv/英雄系统/` |
| 装备 | 购买、合成、成长 | `data/csv/物品系统/` |
| 波次 | 防守正式进攻 | `data/csv/怪物与波次系统/`、`scripts/vscripts/systems/wave_system.lua` |
| 挑战 | 练功、打材料、转职 | `data/csv/挑战与奖励系统/` |
| 天赋 | 随机选奖励 | `data/csv/肉鸽奖励系统/` |
| 长期成长 | 看存档、领取、收集 | `data/csv/存档系统/`、`data/csv/玩家档案系统/` |
| 商店与抽奖 | 购买内容、使用奖券 | `data/csv/商店系统/`、`data/csv/抽奖系统/` |

项目里的 `data/csv/` 是业务配置的主要来源。旧说明可能保留历史描述，例如“五选一转职”；当前塔路线配置和界面有七条。本说明按当前七条路线介绍。

看系统时可以套这五个问题：

1. 玩家从哪里打开它？
2. 需要满足什么条件？
3. 消耗什么？
4. 得到什么？
5. 效果是本局有效，还是会保存到账号？

## 12. 开局速查清单

- [ ] 房主确认模式和难度，新手建议 N1。
- [ ] 看开局天赋，完成选择。
- [ ] 先建城墙，再建主城。
- [ ] 训练伐木工，并确认他们在砍树赚钱。
- [ ] 建箭塔，确认射程能覆盖敌人。
- [ ] 看城墙血量，按需要升级和安排修理工。
- [ ] 人口不够时，使用农场的人口升级。
- [ ] 防线稳定后升级主城，开放金矿和英雄祭坛。
- [ ] 召唤英雄，再学习装备、练功房和转职。
- [ ] 随时看积怪和城墙，挑战前先保证防线安全。
- [ ] 通关后查看存档挑战，结束时确认结算结果。
