# 两个测试入口

项目根目录和桌面只提供“离线逻辑测试”与“联网登录测试”。具体日常操作见根目录 `测试入口说明.txt`。先正常退出旧 Dota 再切换，入口不会终止已有游戏。

| 入口 | 代码与存档 | 适用范围 |
| --- | --- | --- |
| 离线逻辑测试 | 当前 development 源码；本局独立内存档案；无云请求 | 怪物、英雄、技能、建筑、局内背包；允许作弊和调试命令 |
| 联网登录测试 | 已验收 `svt_w24` 冻结副本；四账号独立测试库 | 登录、云端档案、抽奖目录及云数据集成；禁止作弊和数据修改调试命令 |

离线并不代表游戏不需要运行 Steam 客户端；它指不依赖云端认证与存档接口。Tools、development 和显式 `survival_offline_logic_test=1` 必须同时满足。身份仍使用引擎提供的真实 Steam 账号，内存和对局隔离负责区分测试档，避免临时账号标识与原生加载门禁不一致。非 Tools、生产包及网页登录冲突均拒绝启用离线模式。

离线档案不读取任何旧 JSON，不写云端；新局清空，版本序号维持单调以兼容档案保护。原生资源/UI/模式/难度门禁和游戏内调试入口保留，不能把临时 provider 用在正式云端战果结算。抽奖目录、支付及排行榜等云能力需要联网环境；现有永久档案测试限制继续适用。

联网入口复用已验收副本，自动核对并复用或启动本机固定目的 Steam TLS 中转。它仍依赖本机在线，稳定云端出站节点尚待配置。首次网页登录后可明确选择记住浏览器30天，之后有效期内跳过 Steam 登录，但每局仍须确认授权码。退出网页登录会撤销浏览器身份，不删除测试档，不自动终止已批准的局。

离线启动设置 `sv_cheats=1`，联网设置 `sv_cheats=0`。服务端中央开发策略还会读取受信的网页登录配置：只要启用网页登录，就拒绝聊天作弊、资源/英雄/科技/武器/波次/存档等调试修改，即使运行在 development 与 Tools 中也一样；已经注册过的回调同样重新核对权限。正常游戏购买、升级、召唤及只读诊断继续保留。配置缺失或错误时拒绝作弊，不影响正常初始化。

联网实际冻结副本需包含同一门禁。入口按 `publishing/workshop/online_cheat_policy_20261024.json` 核对发布内容标识、受保护策略文件和 production 配置的 SHA-256，防止误用旧版本。完整签名和资源验证在候选构建与安装时执行。此设置不把本地主机变成可信托管服务器；原有独立测试库和战果可信度限制继续适用。

`tools/workshop_test/launch_test.ps1 -Mode Offline|Online -CheckOnly` 只检查本地入口和依赖，不启动游戏或中转。实际进程与安全诊断保存在忽略的 `output/test_entry_runtime`。冻结联网包与当前开发源码不会自动相互覆盖。

2026-10-24 原生离线此前已完成身份一致、加载就绪、模式/难度选择并进入地图，局内加木材命令已生效。两个根 CMD 的只读检查通过，联网 v02 此前已完成真实 Steam 登录、云端读档与在线进度回执。浏览器记住功能已通过53项服务测试并部署，跨日效果由明确 Cookie/数据库期限和重启测试验证，尚未经历实际30天。

## 从游廊测试联网版本

沿用[孤城逐晓 · 封闭测试](https://steamcommunity.com/sharedfiles/filedetails/?id=3824360109)，保持不公开列出、原封面与四账号限制。联网 v03 的签名内容标识为 `549750458285ba1de04436dbeaa0249f5bd587dcf6f6cb914feb84d81d0587d9`，发布序号 `2026102403`。工坊发布与正式下载结果以 `publishing/workshop/test_listing.json` 和本次发布回执为准。

先正常退出旧 Dota，让 Steam 完成该条目更新；再从原游廊条目新建房间并开始。名单内玩家应看到“授权当前 Steam 账号”的网页登录卡和本局短码，使用当前同一 Steam 账号在网页确认授权，返回游戏后继续选择模式和难度。玩家不需要运行本机测试 CMD 或连接助手。若仍显示旧的 `WS4-03` / `Invalid_NotOnDedicatedServer`，先核对 Steam 更新版本；新包的网页登录路径不依赖该凭据。

作者端暂时继续保留固定 Steam TLS 中转，测试时作者电脑及其现有网络需在线。此发布提供游戏下载和网页登录流程，多人服务器托管和延迟仍需分别验证。Tools 模式验收不替代普通游廊外部 HTTP、登录读档、重开同档及多人实测；游廊房间也应保持作弊选项关闭。
