# 个人 HUD 同步与客户端倒计时，2026-09-28

已按用户要求实施。个人资源、建筑、工人、商店解锁及带 player_id 的道具属性变动优先按 player_id 合并；队伍变化与全局阶段变化仍支持各自范围。同队玩家不因他人资源变化重新构建快照。叠加的个人/队伍/全局批次每人最多发送一次，重入更新保留到下一批，非法个人 ID 不退化为广播。

普通怪生成/死亡的 HUD 更新只指向该通道玩家。下一波、挑战阶段、怪物超量警告使用服务端绝对游戏时间截止值，由客户端现有 0.1 秒显示循环更新，游戏暂停时不会继续走。服务端普通波次/超量检查保持运行，但纯计时 tick 不再触发整套 HUD 构建和网络推送。挑战阶段从 0.1 秒轮询改为一个到期任务，边界发奖入口仍检查截止时间。界面加载或重载主动请求一次个人快照，不增加周期性请求。

到期出怪、个人失败、挑战结束和存档保存屏障仍由服务器判定。客户端显示 00:00 不宣布胜负。挑战开始、结束及保存状态变化继续同步。未改动伤害、成长、资源消费或奖励权威。

验证：8 项 Lua（调度、个人波次投影、挑战时间、超量终局、四通道碰撞、挑战建筑位置、难度解锁、快照差量）和 4 项 Node（倒计时、攻速、自动升级/主题、建筑 HUD）通过。1000 次个人更新只产生 1 次本人快照构建/发送；同队其他人不刷新。测试覆盖纯计时 tick 无 HUD 更新、两个个人截止时间独立、无新收包时倒计时、暂停、过期包丢弃、归零等待服务端、慢存档保存等待。
