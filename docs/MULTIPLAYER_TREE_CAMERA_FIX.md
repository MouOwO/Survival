# 2026-09-26 联机镜头、独立资源树与波次碰撞

建造者首次选中时客户端同时定位镜头；实体晚于 NetTable 到达时，现有 HUD 轮询继续恢复。重复事件不反复拉镜头，玩家已选中其他可玩单位时保留其操作。客户端文件已同步至 content 并定向编译，记录位于 `output/multiplayer_tree_camera_20260926/compile.log`。

每个玩家第一次建成主城后，按主城相对主岛中心所在象限生成自己的资源树。四区沿用现有东北树点并随庭院旋转；同区最多四个固定位置，间距 192，各预留 2×2 网格。多人同区各有一棵树，不共享等级。主城重复创建事件不会重复生成个人树。玩家退出后移除其树并恢复该位置的预留。

树等级、工人的默认目标和效率显示均按玩家隔离。英雄和伐木工攻击任意玩家的资源树时，木材记入攻击者的钱包，树等级加成取攻击者自己的树。把其他人的树打升级，只提高树主人的加成；融合工人按原有融合数量计算自己的加成。手动攻击别人家的树会持续到空闲，再按原规则恢复自动采集。额外百分比树伤害作用于实际受击树。

普通波次怪使用已有 `modifier_enemy_wall_ai` 的单位无碰撞状态，并在最终碰撞半径、状态设置完毕后首次放置。出生点不移动，不增加怪物周围扫描或解卡定时器。地面导航和城墙目标逻辑保留；怪物之间可以相互穿过，这是本方案的行为变化。该方案处理单位相互阻挡，地图不可通行区域仍需要正确的 GridNav。
