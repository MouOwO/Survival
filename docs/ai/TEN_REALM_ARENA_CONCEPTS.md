# 一至十戒 · 封闭对战场所概念规范

当前版本：**v2 · 全部 700 × 700 游戏单位正方形主体**。状态：**概念待验收，尚未建模**。本轮交付完整十张独立设计图，用于确认地貌、围合方式、材料及水岸衔接；不修改既有模型、地图或玩法配置。

## 共用要求

- 十处场地分别采用不同地貌，统一 Dota 2 风格的手绘材质语言、适度磨损、自然反光和清晰轮廓。区别落实在地表、围墙、岩层、植被和岸线，不只换色。
- 每处均为**四面完全闭合、上方露天**的独立对战场所。正前方也保留完整低矮实体边界，不留缺墙、门洞或跨墙桥梁。
- 十处场地主体均为 **700 × 700 游戏单位的正方形**，长宽相等；主体尺寸包含四周围墙，不是仅指墙内净空。**外围自然岸地、浅滩与水面在主体之外延伸**，不计入该主体尺寸。
- 每张设计图为 **1536 × 1024 像素**的横向画板，用于容纳整体、俯视与细节视图。图片分辨率与游戏单位尺寸分别表示两种尺度，不能把横向画板解读为长方形场地。此前转生擂台的 1000 × 550、练功房的 900 × 900 分属其他资产要求。
- 战斗面平整、连续，中央至少约三分之二内场保持净空。高树、岩块、晶簇、根系等集中在墙边或外侧，不遮挡中央战斗视线。
- 相对两侧内侧各保留一处小型、不发光的平面落点纹样，作为概念构图预留。它们不代表已新增双人对战、改动传送规则或完成地图接入。
- 围墙外侧保留宽度可读的自然岸地，外岛轮廓不规则。依次表达**干燥地表 → 碎岩/土壤/植被 → 深色湿岸 → 可见水下浅滩 → 较深水域**。
- 各地貌共享平静水面的大体波纹尺度，通过岸材、沉积物和水深形成差别。水面不截断场内战斗面，不采用直立方形底座入水、整圈均匀白沫或硬切贴图边界。
- 采用足够明亮的自然日光，即使沼泽、火山与夜魇也应看清表面结构。没有角色、敌人、强发光、粒子、厚雾、遮挡内场的巨塔或中央巨型雕像。
- 用户用语“地方出生地”本轮**暂按敌方夜魇出生地风格**理解，作为与天辉风格相对应的第十戒概念，待视觉验收确认。

## 十种地貌

以下十处统一采用 **700 × 700 游戏单位正方形主体（含围墙）**。顺序与名称是本轮概念安排，尚未写入关卡或 CSV。

| 戒数 | 概念名称 | 地表与围合特点 | 水岸过渡 |
| --- | --- | --- | --- |
| 1 | 黄沙古垒 | 风积黄沙与磨损砂岩围墙；平坦沙地留在内场，沙丘在外围 | 干沙 → 暗色湿沙 → 水下砂岩浅滩 → 青蓝深水 |
| 2 | 林间古环 | 林土、落叶、苔石墙与根系支撑；树冠避让中央 | 林土与落叶 → 根系卵石 → 湿岸碎石 → 清水 |
| 3 | 沼泽沉垣 | 压实泥炭形成坚实战斗面；腐木与低苔墙围合 | 泥炭 → 湿泥水沟 → 芦苇浅水 → 深绿水域 |
| 4 | 赤岩断谷 | 红砂岩层理、赭色碎砾与低断崖；结构有峡谷特点 | 红岩台阶 → 崩落砾石 → 暗红湿岩 → 碧水 |
| 5 | 霜雪寒垒 | 冻土浅雪与霜白石墙；保留雪、冰、岩石的材质区别 | 积雪 → 冰霜湿岩 → 碎冰浅水 → 冷蓝深水 |
| 6 | 潮礁碧湾 | 浅色珊瑚石、贝砂与低礁围墙；热带海岸质感 | 珊瑚石 → 贝砂潮池 → 海草礁盘 → 碧蓝海水 |
| 7 | 熔岩黑岸 | 冷却玄武岩、焦岩与暗铜；火山环境依靠材料表达 | 冷却熔岩 → 黑礁碎石 → 湿润岩岸 → 深蓝海水 |
| 8 | 紫晶岩庭 | 紫灰矿岩、石英纹脉与低矮晶簇；切面反光但不自发光 | 矿岩 → 石英碎砾 → 湿润矿石 → 清澈水域 |
| 9 | 天辉圣庭 | 浅白石、青金嵌饰、花草与低矮自然建筑；明亮舒展 | 白石花庭 → 苔岩草岸 → 清澈浅滩 → 蓝绿水域 |
| 10 | 夜魇荒庭 | 灰岩遗址、骨白棘饰与枯根；暗色但清晰，区别于火山场 | 灰岩遗址 → 枯根黑泥 → 湿页岩浅滩 → 灰蓝水域 |

## 项目配置对应关系（只读核对）

- 现有项目中“十戒”对应 **`challenge_11` / `encounter_challenge_11` / `ten_sins`**，当前显示名为“进入罪渊（十宗罪）”。入口条目按深渊审判武器等级选择第 N+1 层；它与 `rebirth_01..10` 转生擂台是不同系统。见 [challenge_definitions.csv](../../data/csv/挑战与奖励系统/challenge_definitions.csv) 第 14 行。
- 十个阶段的成员为 `boss_ten_sin_01..10`，固定生成点是 `challenge_11_stage_01_spawn..challenge_11_stage_10_spawn`。各自入口名按序号生成 `challenge_11_stage_01_entry..challenge_11_stage_10_entry`。未来模型接入需保留这些入口与生成点契约，并保证落点可通行。见 [encounter_members.csv](../../data/csv/挑战与奖励系统/encounter_members.csv) 第 14–23 行和 [challenge_session_service.lua](../../scripts/vscripts/systems/challenge_session_service.lua) 的 `current_entry_marker_name`。
- 当前运行逻辑会预生成十个受限制的 Boss，再激活对应阶段；不要把成员表中的 `simultaneous` 字段解释为玩家需要同时与十个 Boss 作战。概念图不改变该运行逻辑。
- [challenge_locations.csv](../../data/csv/挑战与奖励系统/challenge_locations.csv) 将十阶段登记在共用 `challenge_11_room`，`room_radius=2400`。这是既有地点配置，**不能据此推定每张新场地的占地尺寸**。
- 旧视觉地图 `survival_world_v2` 中已有 `commandment_01..10`，排列为三列四排，末两格留空；对应旧地块约 **920 × 1440，Z=384**。数据见 [旧地图布局](../../output/survival_world_v2/layout.json)，构造源为 [survival_reference_regions.cjs](../../tools/survival_reference_regions.cjs)。这些是旧视觉方案，不是本批新场地的尺寸批准；旧图的 `commandment_XX_boss_spawn` 也不等同于运行时 `challenge_11_stage_XX_spawn`。
- 正式入口仍由 [addoninfo.txt](../../addoninfo.txt) 指向 `template_map`。[build_forbidden_regions.csv](../../data/csv/建筑与工人系统/build_forbidden_regions.csv) 记录正式地图尚缺可靠边界坐标，因此本轮不猜测边界、不填导航区域，也不把概念图视为已经替换正式地图。

设计验收清单：

- [ ] 十张图齐全，名称、编号与地貌对应；每张只表达一个场地。
- [ ] 十处主体均为 700 × 700 正方形且尺寸包含围墙；俯视图长宽相等，整体与俯视表达一致。
- [ ] 四面闭合，前墙完整；无门洞或连桥，上方露天。
- [ ] 中央连续平整，约三分之二内场留空，装饰与植被不遮挡战斗。
- [ ] 十种地貌在几何、材料、植被与边界构造上可辨，不只是相同石场换色。
- [ ] 主图完整展示岸线及周边水面；干湿变化、浅滩、水下轮廓和深水均有层次。
- [ ] 俯视图与岸线特写对应主图同一方案，没有互相冲突的墙体或通路。
- [ ] 天辉明亮自然，夜魇暗而可读；夜魇与火山不混为同一种环境。
- [ ] 木、石、土、雪、冰及矿晶有相应表面特征，不依赖发光掩盖质感。
- [ ] 自然岸线外延不被误计入 700 × 700 主体；画板 1536 × 1024 像素与游戏单位尺寸明确区分。

验收后按已确认的 700 × 700 主体尺寸确定墙高、水位、落点与外围岸线延伸，制作模块化模型、材质、碰撞和地图装配，并单独验证导航与实机表现。
