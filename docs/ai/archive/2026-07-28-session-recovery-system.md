用户报告多次断开或界面关闭导致聊天内容丢失；即使重新读取 `PROJECT_CONTEXT.md`、`CURRENT_TASK.md`、`DECISIONS.md` 和 `KNOWN_ISSUES.md`，仍无法恢复断开前尚未落盘的深度研究内容。用户已批准：

## 验收标准

1. `docs/ai/START_HERE.md` 成为新会话的唯一恢复入口。
2. `CURRENT_TASK.md` 只描述一个活跃任务，不再堆叠历史任务。
3. `SESSION_LOG.md` 以追加检查点方式保存研究过程中的关键证据、排除项和下一步。
4. 旧 `CURRENT_TASK.md` 完整迁入 `docs/ai/archive/`，不得丢失既有工程记录。
5. 新会话仅通过项目内文档即可区分：已确认事实、推断、待确认事项和下一步动作。
6. 获得断开前任务的最小线索后，必须先写入检查点，再开始代码调查。
