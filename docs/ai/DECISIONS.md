## DECISION-20261006-WALL-WAVE-ROUTING

波次通道属于PlayerID，物理出怪方向属于已完工城墙区域，二者分离。以配置中四个实际Marker的平均XY为地图中心，右上/左上/左下/右下分别走北/西/南/东，不假设世界原点就是中心。共享出怪点按PlayerID横向排队，默认80中心间距且不小于正式怪直径；未完工城墙保留初始槽位通道。只在城墙及参与通道变化时更新，保持通道对象让已排程出生使用最新位置，不修改原波次数量和生成时钟。缺少必需Marker时不得偷偷换到其他玩家的入口。

正式波次怪上限改为全场共享90，保留10游戏秒连续超限宽限。一个共享时钟、一份全场数量投影，恢复上限以内取消；到期先冻结波次/胜利，再对全部参与者调用原判负清理，不能仅判负当前最多的玩家或允许清理最后一只触发胜利。个人资产与城墙目标保持隔离，练功/非正式挑战计数政策不变。离线并排坐标与448入口几何通过不等于Source2实机寻路已验收。

## DECISION-20261006-SSH-HEALTH

SSH connect 对已验证归属的现有隧道保留进程和监听，后台健康读取最多三次、socket超时三秒、失败间隔0.5秒；不能因一次健康失败自动杀进程或重建隧道。失败状态必须带固定非空error，启动器兼容旧status。健康超时只说明该次访问未成功，不等同于云端服务停机；恢复后沿用原隧道和游戏，无资源编译或存档操作。

## DECISION-20261005-LUMBERJACK-CAMERA

**Decision:** 仅伐木工收益飘字按玩家与实际树汇总，固定0.25秒显示合计；工人界面成长通知固定0.1秒合并。每击资源、攻击成长与原生伤害更新立即处理。永久成长请求读取单个实时字段；科技快照复制变化分区，保留先前值。

**Reason:** 逐击飘字/标签会让移动镜头时的投影和样式更新随工人数与攻速增加；完整属性复制与重复通知额外消耗CPU。减少可验证开销而不改变结算时间或攻击效果。

**Impact:** 同树多人快速伐木看到0.25秒合计收益，按采集者隔离，断线/移除/复用清理，空闲无常驻任务。原生攻击和模型渲染未用离线计数替代实机测量；控制台不可连，实机FPS待复测。

**Date:** 2026-10-05

## DECISION-20261005-SERVER-THINK

**Decision:** 调度器采用索引到期队列，不扫描未来任务或使用会积累过期条目的延迟取消。英雄攻击减甲只读当前三个永久奖励字段，并将同目标下一调度帧的界面通知合并。详细诊断遵守既有默认关闭开关；可选Tools服务端限量聚合采样用于定位具体回调。

**Reason:** game-mode Think耗时警告不能按附近日志归因。消除明确的任务扫描、整份属性复制、重复界面任务与诊断工作，同时保留真实效果和显示，并提供按任务测量依据。

**Impact:** 调度间隔0.05秒、到期业务执行及重入语义保留；50次即时减甲只需要1次界面通知，窄查询无缓存。采样默认停用、无新增周期任务，CPU统计不同于整个引擎帧。当前引擎控制台不可连，不宣称实机11.89ms警告已经消失。

**Date:** 2026-10-05

## DECISION-20261005-FLYING-PERFORMANCE

**Decision:** 新生怪物明确声明fresh_unit，已记录外观按自有部件处理；全场实体发现仅保留给冷恢复。FindAll成功后不再执行FindBy。12类龙形/骨翼/飞毯波次怪复用寒冬飞龙的原生远程模型、攻击动画与弹道，保留项目射程；饰品按品质和不朽部件升级。

**Reason:** 原外观创建与清理反复全场扫描导致生成成本随实体数量增长；近战攻击配置与飞行英雄模型的原生远程动画不匹配。警告从源模型补attach_hitloc及伐木工静态攻击能力一致性修复，不依赖日志抑制或额外周期任务。

**Impact:** 90怪离线fixture消除450次批量全场发现及20745次逐个查询；保留冷恢复、事务回滚和所有873条波次玩法数值。每只两个饰品部件，攻击由引擎处理。离线操作计数与资源验证不代表实际帧率/画面验收，需新局复核。

**Date:** 2026-10-05

# Architecture Decisions

Last Reviewed: 2026-10-05

本文件只保留当前仍适用的长期决策摘要。重构前完整决策记录见 `archive/2026-08-25-pre-knowledge-refactor/DECISIONS.md`。

## 研究取消与建造状态投影（2026-10-05）

研究排队必须满足实际科技和转生条件，不能将缺前置当作可排队等待；资源不足仍允许未扣费排队。技能激活、运行态、商店和服务端请求一致，共享研究所按钮与队列读取当前玩家私有投影。取消按稳定job_id和玩家/建筑权限定位：当前事务先确认回滚成功再撤销完成定时器，等待任务不退款；剩余任务保留顺序与编号、重排同类目标等级。取消关闭对应自动研究，完成/重复/跨玩家请求不能产生退款，回滚失败须保留原任务及定时器。

免费祭坛客户端必须与服务端共享肉鸽次数判定，解锁和价格同时改变，仍遵守唯一建造和英雄状态限制；免费次数在施工完成后消耗。伐木模型即使弹道名为空，原生远程模式仍可能请求attach_attack1；普通与融合伐木工均使用配置射程的直接攻击，保留原攻击事件与时钟，不能为消除警告新增逐击定时器。

## 城墙近战进位许可（2026-10-03）

候位间距由全前排后缘、等待者半径和小余量计算，不能用固定160退让制造一整排空位。只有已经过近而需要向后退的怪补偿移动停步误差；普通后方来怪不额外拉远。按半径及前排外缘缓存合法目标，普通和退回目标各自验证导航，分数半径不能用整数打包键混用缓存。稳定队列保持原订单，不为视觉紧凑增加逐帧搬移或重复寻路。

modifier stack更新不等于同帧原生phase/root/disarm已生效。进位首次MOVE必须在下一引擎帧发出，复用一次现有Think后恢复0.5秒，不常驻逐帧循环；预约过期前必须有机会恢复静默失败的MOVE，不能让同为三秒的预约撤销永远先于恢复。native IsIdle=true/GetForceAttackTarget=nil可能仍持续命中，稳定攻击以状态和真实attack事件为准。实机验收限定初始/补位完成时限，不接受最终等几十秒才凑够四只的假通过。

四个逻辑预约不能证明四个物理位置可达。Hull32在256宽入口没有独立站位误差余量；近墙最多四个独占持有者用地面导航、临时单位碰撞豁免和一次精确落位，前排保留豁免防止后排推偏，其余怪退后候位且禁攻击。不能用更多透明导航墙切割零余量门口；不能让未获许可或无候选者回退无约束原生攻击。原攻击时钟只在真实状态变化时接线；修复测试需模拟移动停止误差与单位碰撞，并在独立引擎检查持续命中、零后排命中和死亡补位，不以直接写到理想坐标的离线测试代替实机。

## 选中单位头像身份与布局（2026-10-03）

选中请求/推送与常规英雄统计NetTable必须共享ui/portrait_metadata映射，只装饰投影副本；不得让常规属性刷新丢失头像身份并触发unsupported_portrait。保持权威统计、版本及发布时钟，失效实体或真实不支持单位仍回退原生头像。ScenePanel加载以头像key和实际Scene对象为准，稳定帧不得重载，节点被重建时必须重新加载。Panorama未布局位置可能是极大有限数，不能只用isFinite验证；几何数值必须可用于真实HUD定位，诊断值与锚点定位分开。编译与行为模拟不能代替实机持续显示验收。

## 陨石凤凰落地效果（2026-10-02）

陨石使用原生成功重生phoenix_supernova_reborn的完整17层子图，不叠加旧自制爆炸或使用死亡碎蛋效果。原生CP1不是通用范围参数；固定500必须保留原生参数、绘制、颜色、发射和寿命，仅派生空间尺寸/运动及CP0距离约束，预算计入每层渲染包络。原生CP3绝对写入改为落地点相对世界快照，避免方向依赖世界原点。完整尾效独立于被命中单位和玩法cast锁，先生成后伤害，原生最长7秒、一次性8秒清理；任何视觉故障不得改变伤害、时序、熔岩或减速。source生成时的PENDING不能冒充编译验收，必须读取当前compiled DATA和实际官方日志；数值约束通过仍不能代替实机光晕、投影及屏幕表现验收。

## 塔头顶文字排布（2026-10-02）

名字用固定108宽文字框内居中，与血条共享屏幕中心，不依赖fit-children与horizontal-align叠加来证明文字居中。字号18、加粗，R浅蓝、SR紫、SSR金（UR同金）；名字与血条相贴，星级与名字相贴，品质标在血条左侧且垂直平齐。字号变化必须同步名字行高、标签高度与BAR_TOP，并维持血条屏幕锚与图标相对偏移。施工隐藏与服务端品质投影仍为权威；离线几何/样式检查与官方编译不能替代实机中文字体的像素验收。

## 特效品质规则（2026-10-01，用户明确约定）

技能特效皮肤按防御塔显示品质区分，同品质1–5级保持同一种皮肤；后续制作沿用此规则。激光：R默认修补匠Q，SR TI10不朽Q，SSR TI10不朽神杖Q（含红星进阶）。不得按继承的激光技能等级切皮肤。品质使用 `tower_rank_projection` 的实际显示结果，不能使用路线CSV中旧的品质字段；皮肤切换不改变伤害数值、结算时钟和技能继承。

雷电塔：R保留原连锁闪电，SR使用“风暴之示”原生Q，SSR第三阶段按用户最新反馈改回宙斯原生连锁闪电（含红星进阶），取消过细的金色连线及附加金色命中特效。塔雷暴继续使用萨尔“风暴串联之震”原生R（ItemDef23655），范围读取本技能半径，沿用技能持续时间。2026-10-02用户单独指定英雄落雷／怒雷改为宙斯“真霹实雳”原生W（ItemDef5412）：每次雷击独立主落雷与施法效果，保留原生地面裂痕自然消退及秒杀残留，使用对应饰品音效。hero_strike与塔strike分开配置，英雄不再复用塔区域雷暴；原生点落雷没有范围CP，不把本技能400范围写入其端点。仅换表现，不应用原生眩晕、沉默或额外伤害，不改变原伤害或结算时钟。本机ItemDef核对风暴之示12323只改Q，真霹实雳5412才改W，纯金不朽诸神18563改静电场/跳跃，不可编造不存在的风暴之示W或纯金Q资源。

## 武器持有视觉与主手视觉（2026-10-02）

猴子与主宰的武器饰品按main_hand系列映射，同系列强化共用饰品；空手与成长之剑为默认武器。武器槽与全身饰品分离，替换模型/皮肤/材质和该槽原生常驻粒子，保留身体及其他饰品，数值与动作/技能不受原生ItemDef影响。原子创建成功才清旧槽，故障保旧并复用现有poll重试，败北及换英雄事务回调必须补清锁忙时遗漏的旧槽；失效hero用缓存的状态token与entindex清理，新world禁止触碰旧粒子ID。带骨骼本地偏移的CP使用不可见原生父子锚点，不能将SetParticleControlEnt的后备origin当偏移；原生子粒子内建快照由资源依赖加载，禁止引入未证实的snapshot Lua API。主宰当前至宝身体保留，霜望好战者缺失专用快照时仅使用准确模型与现有冰光，不能换成默认剑轮廓。

用户指定获得「传说：深渊审判」显示原生神杖脚底光圈。库存持有状态与main_hand装备状态分开：owned_particle按完整库存快照触发，legend_abyss的00～10共用原生scepter_aura；升阶及切换主手不重建脚底，最后一份移除才结束。脚底CP0随AbsOrigin，不挂武器/身体骨骼，不授予原生物品或属性。复用weapon_visual的0.25秒生命周期，独立清理、败北迟到事件保护及reset/engine回调重入保护；只核验本机原生资源与离线流程，不声称完成实机画面验收。

## 怪物碰撞与城墙封路（2026-10-02）

正式波次半径由生成末尾的collision profile设置，皮肤/model scale不能改战斗hull；普通、小Boss、首领与飞行波怪默认都32，练功/非正式飞行/挑战保持独立政策。城墙保持256方形本体，在静态导航/高程双侧一致的窄门仅补短侧缝，不以第一只怪物决定封路方向，不泛化封堵开放地面。近战最多四个接触位按实际直径排布，AI与预约共用到位条件，未到位预约不能永久阻塞前排；沿用命令去重与原攻击时钟。现有观察只在当前真实重叠时纠位，观察间跨越检测限已确认封闭gate，避免误拦合法外角绕行。不得把离线导航/模块测试或历史开放场景实测当作当前地图群体物理验收。

## DECISION-001

**Decision:** 本地 Workshop/LAN 联调采用候选同机拓扑，Python API 保持绑定 `127.0.0.1:8765`；正常发布 Arcade 拓扑暂定 `MODEL-D`。

**Impact:** 生产 Session Foundation 在最小拓扑实验完成前暂停；不得把 Lobby Owner、Game Server、Lua 主机和 Python 主机视为同一实体。LAN API 暴露仍必须另立安全任务。

**Date:** 2026-08-23; qualified 2026-08-25

**Decision:** 删除旧局内钓鱼持久化；在线奖励只使用独立 online checkpoint 链路。

**Reason:** 避免两套 session、幂等和计时状态并存。

**Date:** 2026-08-23

## DECISION-003

**Decision:** 永久玩家身份由服务端 Steam Account ID 经 Python 稳定 pepper HMAC-SHA256 后入库；玩法属性默认值来自 CSV。

**Reason:** 分离局内 PlayerID 与永久身份，并消除 Lua/Python/SQL 的重复默认值。

**Impact:** pepper 必须长期稳定且仅存在服务端；`player_gameplay_stats.csv` 是默认值权威源。

**Date:** 2026-08-20

## DECISION-004

**Decision:** 永久在线时长只累计同一 session、租约内相邻 checkpoint 的差值。

**Reason:** 墙钟时间和客户端上报不能可靠表示有效在线时间。

**Impact:** 首次、新 session、超租约、离线间隔与重复 request 均不得重复累计。
