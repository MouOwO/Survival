# 决策

- 不靠关闭全部特效、减少实际伤害或降低攻击次数规避性能问题。
- 先消除无效音效和已确认的 Lua 记录累积，再以实际负载定位剩余瓶颈。
- 已确认的寒冰锥、奥术弹幕每枚落地效果及艾欧外观粒子保留。
- 原生资源取自本机游戏 VPK，所有编译产物保留可恢复原件。离线内存/CPU与真实客户端帧时间分别报告。
- 研究置灰由前置、转生与队列限制控制，木材/金币余额只在操作入口与真实扣费时核对。共享研究所原生技能保持可用，个人 runtime 控制各自灰度/满级隐藏。
- 满级中间技能按原生身份隐藏，不以可见数量裁切原生面板；保留后面的未完成科技与原生 tooltip/热键绑定。
- 一次性 native 粒子 Release 表示交还引擎自然结束，不等同于消灭屏幕粒子。代理记录不再保留有限动画 30 秒；持续效果仍必须 Destroy/Release。
- 单个原生塔观察者以逐事件精确转发和创建失败后备保障业务一致；实机计数相符仍不能替代最高密度的性能对照。
- 塔技能缓存随真实 apply 失效；不长期用 entindex 储存死塔记录，避免编号复用串技能。原生伤害、攻击速度和每枚技能爆炸不因缓存改变。
- 观察到其他会话同步工程/操作窗口时保留其修改，记录 HEAD、截图和自己的恢复点。共享窗口未确认空闲前不作抢占输入或重新开图。
