## 两个测试命令

在 **Workshop Tools 测试对局的聊天输入框**输入完整命令并发送：

| 命令 | 远端实际操作 |
| --- | --- |
| `refreshmoney` | 清除当前账号支付获得的道具，并扣回这些订单实际增加的属性；保留其他进度。清理成功后可重新购买。 |
| `refreshdata` | 当前账号存档、道具、权益、永久效果等恢复新账号初始值；清除派生钓鱼奖励，允许重新购买。新号默认值不一定全部为数字 0。 |

必须等到“远端已更新”提示后再购买。清理会先查清未完成订单，并关闭未付款订单；网络异常时保持原数据，按提示重试同一命令。已付订单和清理审计记录保留，历史回调不会把已清理道具重新发回来。清理不是退款。

命令作用于发送命令的玩家，不能在文本里指定其他账号。目前仅为账号 **1014036256** 开启。已在本局召唤的英雄和生成的单位不会被清理命令删除，检验全新账号的开局表现需要重开一局。
