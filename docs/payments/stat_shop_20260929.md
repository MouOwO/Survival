## 直接验证

1. 进入一局常规模式，等待存档加载，点击顶部 **商城**。
2. 先选择“初始木材 +100”或“初始金币 +100”，记录商城显示的“存档：购买前 → 购买后”和当前资源精确数值。
3. 点击微信购买、扫码支付，等待成功提示。商城显示本笔实际入账的前值、后值及增量，并刷新本局属性与资源。顶部资源可能缩写为“亿”，商城使用精确数字。
4. 护甲看城墙护甲面板；血量看**生命上限**，受伤城墙保持原生命比例。箭塔看攻击面板；有攻击百分比科技时，最终攻击增量会被倍率放大，存档固定加成仍增加 100。
5. 重开一局可检验永久开局加成。已结算冻结的对局会提示下局生效。

现有建筑随存档投影刷新，未建城墙或箭塔时在建造后生效。资源生产、消耗会影响净余额，付款记录里的增量为本单独立结果。
