## 玩家操作

1. 用项目现有的测试启动器进入 `survival/template_map`，完成模式选择、等待存档加载。
2. 账号获准测试后，屏幕右侧出现 **微信支付测试**。点击后核对商品和 **¥0.10**。
3. 点击 **生成微信付款码 ¥0.10**，二维码直接出现在游戏弹窗中；无需切换窗口。也可以使用“备用：在浏览器打开”，或复制链接到电脑浏览器。
4. 使用手机微信扫码付款。付款操作由玩家完成。
5. 面板自动查询并刷新存档；也可以点击“查询付款结果”。订单完成后隐藏二维码并禁止重复购买。断线后重新进入游戏，存档仍保留。

入口不出现：先确认已选择模式、存档加载成功，再确认当前 Steam 账号已加入测试名单。名单在服务端维护，不能由玩家输入 Steam ID 冒领。

已经拥有该奖励的账号不能再次购买。如果二维码生成后，账号通过抽奖等其他途径获得该奖励，到账记录会保留为 `paid_review`，页面提示联系开发者处理退款，不会重复发奖或擅自换成积分。

## 服务端位置与账号开通

服务：`goufayu-payment.service`；监听 `127.0.0.1:8766`；Nginx 仅代理明确列出的支付路径。游戏存档服务继续使用 `127.0.0.1:8765`，没有为支付开放其公网接口或改动其出站网络限制。

部署版本：`/opt/goufayu/payments/20260928-payment04`，`/opt/goufayu/payments/current` 指向它。游戏二维码由后端生成黑白矩阵、Panorama 原生面板绘制，避免依赖 Steam 浏览器弹出或远程图片加载。

配置：`/etc/goufayu-payment/config.json`。密钥：`/etc/goufayu-payment/wechat/`，只允许 root 和独立支付服务用户读取；没有放入游戏客户端、Git 或聊天输出。

由维护者在已验证的 ECS 上执行以下命令，只传 SteamID64 或 Dota 好友数字 ID，不传密码：

```sh
/opt/goufayu/payments/current/.venv/bin/python \
  /opt/goufayu/payments/current/payment_backend/enable_account.py STEAM数字ID
```

此操作仅开通测试账号并重启支付服务，不会下单或扣款。当前只开通已从真实测试对局识别的账号 1014036256，避免对普通玩家开放测试商品；不要用示例账号替代。

订单数据库：`payments.orders`，独立受限角色 `goufayu_payment` 只有指定函数权限。价格、商品、数量和账号在服务端确定。奖励、对应属性、存档版本号、订单发奖状态在同一个数据库事务中更新。已有存档写入使用的锁顺序和版本控制保持一致。

微信通知 URL 自动随服务端下单传入：`https://pay.xiaofengnet.com/v1/payments/wechat/notify`。无需再去平台填写商品价格或在客户端放密钥。收银页 URL 由订单生成，不要公开分享；持有链接的人可以为该订单付款，奖励仍属于下单账号。

订单有效期 30 分钟。后台每 10 秒处理到期可查询的待支付订单，核实微信最终状态；查单确认成功也会补发。网络失败保留原订单，不能因此创建另一笔同账号未完成订单。未付款到期订单经微信确认关闭后才释放。

## 备份与停用

`goufayu-payment-backup.timer` 每 6 小时保存游戏和支付 **同一数据库快照**，文件在 `/var/backups/goufayu-payment/game-and-payments-*.dump`，附 SHA256。首次完整备份已验证包含 `payments.orders`。目前是本机备份，未新增异地备份。

旧的游戏备份只包含 `public/extensions`，**不能单独用于恢复带真实收款记录的游戏**。支付启用后需使用同时包含 `public/extensions/payments` 的完整备份，并在隔离环境做恢复演练，核对支付订单与存档后再切换；旧迁移工具可能拒绝新 `payments` schema，不能直接强行绕过检查。

暂停新增购买时移除测试账号并重启支付服务，保留回调和查单处理已有订单。不要删除订单表、清空真实存档或撤销密钥作为排障手段。退款需要按真实微信交易记录处理，当前版本不提供自动退款接口。

参考：[微信 Native 下单](https://pay.wechatpay.cn/doc/v3/merchant/4012791877)、[支付成功通知](https://pay.wechatpay.cn/doc/v3/merchant/4012791861)。
