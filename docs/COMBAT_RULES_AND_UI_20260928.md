# 2026-09-28 已确认的战斗规则与界面修改

## 已实施

- 攻速主面板显示当前百分比。名称与数值均可悬停，显示基础间隔、科技/存档/合体/性格/领袖及临时效果、当前间隔；清除旧 UI 把百分比覆盖回频率及显示旧频率加成行的问题。频率字段仍供内部技能与逻辑使用，不把数字改单位后传给战斗代码。
- 伐木工先从基础间隔扣除固定减间隔，再应用百分比倍率。普通 1.5 秒、合体减 0.5 秒不变；合体加 60% 攻速得到 160% 和 0.625 秒。保留既有最小间隔保护。英雄与箭塔原本已先减间隔，补齐来源描述和实际百分比投影；英雄装备、科技倍率与临时光环保持引擎实际叠加方式。
- 箭塔逐击成长只写攻击者的局内个人池，普通升级与跨阶段在同一单位上保留；合成终极塔从材料实际攻击继承一次，终极塔后续个人成长独立积累，英雄属性同步不覆盖个人成长。删除两个玩家共享逐击成长池。静态科技/存档加成和按时间发放的祝福规则保留。
- 逐击成长通过专用事件和注册表直接更新单塔，不广播永久属性变化或扫描地图。
- 自动升级资源规则按用户要求保留。
- 挑战 30 分钟到时立即结束挑战并移除挑战怪，屏蔽后续挑战击杀发奖；进入保存状态，停止新存档奖励意图，先补交已有在线计时。等待所有参与者（含断线玩家）已有存档请求确认，再 SetGameWinner。慢请求或网络失败沿用原幂等编号重试，不设置丢弃待保存奖励的强制超时。保存期间顶部提示“挑战结束 · 正在保存奖励”。服务端持续不可用时会继续等待；不能承诺外部服务断电或玩家强退时仍一定持久化。
- 顶部导航与波次之间增加“简化特效：开/关”。每位玩家独立决定画面，覆盖英雄被动、专属技能、饰品、箭塔命中/技能/持续光效。保留原生弹道、攻击范围和升级金光，伤害、命中和技能时序不变。持续粒子切换时重建控制点；已释放的一次性粒子自然结束。防止重复释放、失效实体重绑和高频切换。
- 存档配色统一由 data/ui/archive_theme.json 管理。CSS 模板与脚本主题共用生成 token，tools/build_archive_theme.py 可重建；名称、数量、选中项、禁用按钮和悬停说明使用相同主题应用入口。
