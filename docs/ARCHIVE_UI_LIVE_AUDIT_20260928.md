## 图案下方文字与弹窗一致（最终实现）

卡片位于额外 scale3d 缩放的窗口内，弹窗位于原生比例的独立层。仅设置相同字体或子标签反向缩放不能稳定消除文字过滤差异。最终将名称、数量、等级、兑换费用和晋升文字绘制到 ArchiveNativeCardText，使用与弹窗相同的字体/正常字重、标题30px/数值22px/辅助19px。原标签保持布局但 opacity=0；独立文字层不接收鼠标输入，原按钮与悬停仍负责交互。图标、背景、四列神兵布局保留。

文字层按可见卡片位置定位，并按网格裁切；布局/滚动未变化时不重复定位，关闭页面时取消更新并隐藏。首帧零尺寸受保护。卡片包装移至等级及费用创建之后，保证辅助文字锚定自己的容器。实机核对等级位于底行、数量居中；滚动后文字整体上移136像素，离开网格的名称隐藏，关闭时原生层 visible=false。证据：native_scroll_verified.log、card_text_verified.log、card_title_matched_preview.png。编译与回归通过。验收期间临时 host_timescale 0.1 已恢复 1。
