# 怪物动作、头像与复活位置修复（2026-09-27）

## 问题与修改

- 十宗罪待挑战状态原来使用 STUNNED；改为无敌、定身、禁止命令、缴械、沉默与禁用物品，保留自然待机。当前安装的 Valve 模型中，骷髅王至宝与女王至宝的待机序列分别包含 `wk_sk_idle` 和 `qop_arc_idle`，并非通用 `idle`。怪物身体交由 NPC 活动系统选择动作，骨骼合并挂件继承身体姿态，不再独立强制播放 `idle`。普通挑战共用建筑外观入口也作了对应处理。
- 实机 console.log 显示 Doom 头像每秒交替出现 `HIDE reason=unsupported_portrait` 和 `SCENE_SET`。定时属性 NetTable 缺失头像身份字段，直接选中事件又补回，造成反复重建与原头像露出。两个服务现在复用同一份头像身份投影；客户端同实体纯属性更新保留身份，跨实体和显式清空仍正常处理。横线是否完全消失仍需实机验收。
- 全部模型头像统一为不透明的深色柔和背景，取消底部地面阴影。保留原镜头、灯光、动态 3D 模型。`ui.vfx` 的图像输入键为 `Texture`；已检查编译材质实际引用 512×512 新纹理，而非默认贴图。
- 正式英雄召唤时设置复活点；死亡时按本人主基地安全落点重新设置，复活后复用 F2 回程服务重新检查占位、移动、退出房间并跟随镜头。对重复回调、非正式单位、已淘汰玩家及旧会话均作限制；复活不显示手动回城成功提示。
