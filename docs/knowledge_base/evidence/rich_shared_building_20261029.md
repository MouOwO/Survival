# 丰饶跨基地移动与建墙｜2026-10-29

用户反馈丰饶不能到其他位置建城墙，且建造者使用闪烁仍出不去；本轮明确按可离开初始基地、前往其他可建造基地处理。此前“丰饶私人院落不变”只保留为旧实现，不再覆盖本轮规则。

## 当前规则与实现

丰饶建造者可在本模式边界内沿合法原生导航移动、闪烁，guard不会因为离开初始院落而拉回；离开丰饶模式边界仍拒绝。初始出生点和player_id不变。完整建筑占地可以位于任意一座已登记高台内，城墙仍为4×4个64码格；不能跨两平台、覆盖低地水面、道路或越界。四高台矩形不扩大，地图及编译资源不变。

原生四个丰饶玩家标记的实际地面均为Z256。本轮在layout.json及生成mode_spawn_config中配置256±16，以地形确定成员，不把初始化时临时导航障碍永久缓存成院落缺口，也不再把导航开放的Z0水面混入可建区。真正放置仍检查实时导航、坡度、树、单位、已占用格。生成器和配置负例验证相应配套。

rich_region_service提供region_at，物理平台与玩家出生slot分离；builder_work_position_service扩大搜索边界到丰饶模式，仍逐采样检查地面、占用及真实CanFindPath；grid_placement_router下发整个丰饶区预览边界，放置许可仍由完整占地校验决定。

资源树按主城实际所在院落选择原来的固定边缘片区，同院最多四名玩家各取独立空槽；个人树、收入和Lv2奖励仍按player_id。丰饶波次按实际城墙优先选择对应的原中央出怪标记，无墙时回退主城，再无基地回退初始区。与墙/主城创建、移动、销毁联动，群组按庭院切向错开，不合并个人配额。极寒沿用原主城优先；其他模式权限与个人城墙限额保留。
