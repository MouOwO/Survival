## 正式错峰备选

当前只实现压测工具错峰，正式后台异步退出队列尚未实现或部署。玩家可先离开界面，但后台应先持久化稳定账号/会话/请求ID和真实接收时点，再限量处理昂贵结算；不能把最后存档留在可能关闭的Dota计时器里。

复用现有同事务checkpoint outbox及幂等回执，仍需明确已接收/处理中/完成协议、有界后台领取、按账号顺序、旧会话隔离和重启恢复。权威退出时间、跨天日期、配置与权益上下文在接收时固定，排队不能改变在线奖励/租约/每日额度。重复请求先确认已有回执，不另造奖励ID。SQLite/数据库全局大锁不会替代这些正确性机制。
