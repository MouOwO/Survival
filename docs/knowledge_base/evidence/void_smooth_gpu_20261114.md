# 2026-11-14 虚空震爆平滑移动与 GPU 验证

本轮仅本地更新，后台未改。寒冰锥保留每波十枚同时下落及原有冰冻地面；虚空震爆气旋改用原生逐渲染帧计算位置，附着后直接绑定目标。伤害、减速、速度、寿命与共享战斗调度频率不变。

## 实现与成本

`hero_passive_skill_service.lua` 使用 `particles/survival/skills/void_cyclone_smooth.vpcf`，预载入口同步更新。game 的 `art/effects/void_smooth/source` 与 content 中同名源文件字节一致；正式编译资源已生成。

追踪与小气旋由 CP20 锚点加 CP21 速度乘锚点变化年龄，在原生渲染阶段计算 CP0/3；年龄限制为 0.12 秒，防止停止收包时无限外推。附着活目标后使用一次 `SetParticleControlEnt`；目标死亡时解绑并停在最后位置。资源继续复用 Valve 风杖完整可见子图，只增加无渲染器的父系统、一个不可见维持粒子及三个常数成本向量运算，没有叠加可见特效层。

初始化每个气旋 O(1)，创建一个父粒子；稳定追踪每次原调度回调仅发送变化锚点，速度变化时才发送速度，旧实现每次写两个位置 CP。附着稳定状态为零重复 CP/实体绑定写入；附着、死亡解绑、销毁各为 O(1)。每个渲染帧每个气旋三项向量运算；空间 O(A)，A 为现存气旋数。原有 O(A+K) 活动气旋及范围命中处理不变，没有新增全场遍历、实体、定时器或提高范围查询频率。原生单例追踪→附着→死亡→结束计数为创建 1、释放 1、绑定 1、解绑 1、CP 写入 9；此为该条真实运行路径计数，不是统一每秒预算。
