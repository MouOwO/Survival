# 本地测试副本资源瘦身（2026-11-18）

本轮使用 Git 稀疏检出收起八套测试副本中可还原的重复资源，确认回收约 40.702 GiB，涉及 89,328 个工作副本文件。原提交和干净状态保持，代码及证明文件逐 SHA256 复核一致；Git/LFS 还原对象继续保留。游戏运行文件未改动。

同日第二轮专门清理媒体副本：收起 34,992 个图片副本和 56 个视频副本，额外回收约 18.983 GiB。全部媒体逐字节核验，实际读取并校验 3,789 个不重复的本地 Git 还原对象；15,680 个保留的源码和控制文件重新读取核对 SHA256，测试副本仍保持原提交和干净状态。正式素材原件、代码、证明及尚未确认存在可替代副本的历史录像保留。

处理前验证了资源与本地 Git 对象的对应关系，并实际读取、校验还原对象。首轮处理后重新读取全部保留普通文件；媒体轮重新读取保留的源码和控制文件，其他相关保留文件通过元数据及 Git 状态复核。首轮曾遇到 Windows 长路径边界，停止检查后通过仅对当前 Git 调用启用长路径支持完成补验，原中断记录保留。

需要在这些测试副本中使用美术或地图资源时，先在对应副本目录恢复完整检出：

```text
git -c core.longpaths=true sparse-checkout disable
```

恢复会重新占用相应空间。Git 对象和分支属于还原依据，后续清理应继续保留。
