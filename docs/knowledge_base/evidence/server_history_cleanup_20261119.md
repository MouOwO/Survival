完整旧PG数据归档位于服务器，**没有完成本轮PG数据的独立异地全量副本**。本机D:/Survival_加密备份/server_history_cleanup_metadata_20261119/batch01至batch06保存真实的DPAPI加密恢复元数据，包含原文件摘要清单与退出容器恢复定义，均完成加解密一致性验证；不能把这些小文件称为PG数据全量异地备份。它们的六份真实回执已登记。
