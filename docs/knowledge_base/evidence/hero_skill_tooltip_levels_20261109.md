## 定位与生命周期

ability_tooltip在原有最多五条字段遍历中记录是否存在英雄LV行，不增加额外场景查询或遍历。共享PlaceAbilityAbove按实际root可用宽度、UI缩放及锚点上方高度限界；700和920是首选值，不是越出屏幕的固定尺寸。
