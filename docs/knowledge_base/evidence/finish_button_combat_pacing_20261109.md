## 性能成本与边界

令J为待补怪记录数（准备队列最多160），K为本次取消的所属记录数。初始化O(1)，无待办时无准备计时器、场景遍历、网络调用；入队/弹出/取消单条O(log J)，所属清理O(K log J)，空间O(J)。只操作已索引的死亡记录和该房间已有最多十个句柄，不新增全图或全玩家定时扫描。

准备每个引擎帧最多2个任务，使用真实耗时钟设2ms预算；单次原生创建不可中断，可能超预算。满额、加载失败或调度过载时仍可能触发正常创建退路，不能承诺消除全部帧时间尖峰。1秒变1.5秒时，持续立即击杀的理论补怪循环频率下降约三分之一；实际FPS还受Q视觉、饰品和原生渲染等影响。
