## 运行规则

- 生成位置使用 `wave.get_player_spawn_marker()` 的实际模式路由。8方向、3环，最多24候选；默认距离360—840，检查完整128足迹、模式区域、地面高度、GridNav、树木、单位和所有玩家建筑预留，不退回墙边或其他模式区域。四名玩家共用同一入口时可容纳16座，缺少安全位置时等待重试。
- 存档怪物读取自身固定终值，不调用波次或转生倍率。N11以上也读取同一挑战的 N1 固定属性；生命、攻击、护甲、攻速不随模式或本局难度再乘倍率。
- 视频明确的 N 解锁条件由服务器执行；无 N 条件的旧社交类入口保留原 N1 默认。通天塔仅极寒或天灾 N10以上；不会借用客户端模式提示作为准入依据。
- 前女友奖励要求瑞兽赐福累计抽奖次数 **>100**，好基友要求邀请函累计抽奖次数 **>100**，老婆和侍妾要求义帖累计抽奖次数 **>100**。这是获取奖励的条件，允许挑战但必须告知未满足时不发对应奖励；不是余额，也不是≥100。
- 绿茵挑战召唤一群足球怪，项目采用5只；只有全组击败后发一次奖励。中途生成失败要清理已生成怪物，并保留本局挑战次数供重试。
- 返回仅重新选择自己的正式英雄，保留阶段。顶部“结束我的挑战”才结束自己的挑战，队友可继续；全部结束后等待奖励保存屏障再结算。
- 无尽跳关从默认步长1依次增加至2／5／10／20，不能退回；仅实际清掉的波次发奖，不给跳过的层白送积分或装备。
- 普通无尽与单人塔在本局各可开启一次，前者结束后可进入塔；不同玩法重新从步长1开始，不允许同时运行。塔结束即结束本人阶段，因此先进入塔后不能回头补普通无尽。
- 无尽与通天塔每10层积分增加100%。塔的具体更高倍率未在视频展示，项目采用2倍；无尽每20层、塔每15层获得一件存档装备，品质概率随实际层数提升。塔为单人奖励，结束后立即结束该玩家的存档挑战并进入保存流程。
- N21以上奖励准入按当前模式真实难度配置验证，不能把普通模式随意放开到N50。合作名单、模式、难度在获胜时冻结；召唤入口不能在奖励服务拒绝初始化后继续开放。
