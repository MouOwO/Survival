## 发行联动

每次走固定打包入口更新公开游廊，Steam 官方下载与检查点完成后，读取官网下载首页和版本清单。核对序号、manifest、逐卷字节及摘要、助手源码摘要、公开准入，确认后完整验证 EXE 摘要。官网仍为旧版时按当前检查点生成候选并保留任务待更新，返回非零，防止调用方在官网更新前把整个任务收口。新候选需要真实授权验收，之后从官网回读，再继续原任务。成功的 Steam 上传和官方下载步骤复用，不重复上传。说明见 tools/release_packager/README.md。

初始化沿用一次有上限的 Windows 进程快照。补开用两次按 PID 核对原始程序和创建时间、一次参数查询，并以原生句柄约束存活进程。稳定阶段无新增轮询、扫描或游戏帧操作，沿用既有桥接增量读取。发行侧逐资源身份比较有固定清单规模，每次检查最多读取一次首页、版本清单及至多一个完整 EXE。
