## 问题与修改

用户线上截图中的剑圣「剑刃风暴」在未到六转时仍亮色。0804 源码已经包含逻辑锁定状态到技能栏的投影；本轮修改前该文件与 0804 所绑定 game `32ef4951041f3cc2e115fe2ad114b3d030acbf80` 的版本无差异。因此不能将问题简单归因于本地没有添加置灰逻辑。

实际发现的兼容缺口在 `update_hero_skill_projection`：从 NetTable 读回的 `snapshot.skills` 一旦使用字符串序号（如 `"1"`），`ipairs` 就跳过全部技能。索引为空后，通用运行投影仍为 `available=1`；为保留图标而设置的原生等级 1 不能代表技能已激活。

将这一处遍历改为 `pairs`，继续逐行校验技能定义、等级和锁定值，再按能力名称建立索引；行顺序不参与显示判定。数字序号、字符串序号都能保留真实的 `locked=1/level=0`。玩家、英雄、版本、实际单位句柄与归属的校验及缓存失效逻辑沿用原实现。前端已有置灰和 hover 保护，因此没有修改 Panorama 或 content，也没有产生新的客户端编译资源。

本轮通过受控 NetTable 序列化夹具复现了与截图一致的失败，未抓取该线上局的实际服务端快照；字符串序号是已经证实的代码缺口，仍须在新包普通客户端确认截图问题是否完整消失。
