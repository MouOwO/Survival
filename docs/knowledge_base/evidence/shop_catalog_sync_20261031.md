- 四人游廊实际连接的 WS4 API 仍使用 `47accd81d92265b93c243efc876cbd588e9f260ed8a8d7ff9e9afa1943ec9a9e`。用已发布 d573 发起真实 `commerce_catalog`，HTTP200但业务返回 `ok=false,error=archive_config_mismatch`，0商品。

## 已准备的修复

候选仅面向四账号 WS4 实例：以冻结的已发布 d573 后台构建新的独立候选，保留 WS4 原鉴权包装、身份映射、配置、密钥与四账号范围，不改支付服务或另一套原 API。五项数据库合同补齐保留旧配置分支与旧回执，不接受任意新 hash。
