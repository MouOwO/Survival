# 2026-10-28 连续悬停属性弹窗修复

用户复现：存档积分道具网格中来回移动鼠标到不同物品，停止后弹窗有时不出现，需要再移入；要求其他位置的说明也顺畅显示。

## 原因与修改

- 原共享dismiss策略只判断鼠标是否进入浮层，忽略浮层可能与当前道具重叠，导致同一处稳定悬停也被自动关闭。共享策略升级为1.0.3，当前源道具区域优先，不再被覆盖自身的弹窗误关闭。
- 存档V10和收藏离开回调改为携带具体道具，旧道具的迟到事件不能处理新弹窗；共享renderer的来源退出即时释放旧锁。
- 存档、收藏、签到共享renderer接入当前可见道具列表。仅在一次悬停期间每30ms核对鼠标与来源，漏掉原生mouseover也能切到真实光标下的道具；网格检查裁剪边界和源/祖先可见性。鼠标离开图标区、关闭、切页、Dispose后停止，空闲HUD不扫描。
- 当前道具仍在鼠标下时复用显示内容和全部材质，不重建面板；更新数据继续用原权威快照。长说明保留实际滚动区域，进入长说明不跳到其后方图标。
- 合并来源离开的延迟隐藏请求，避免连续跟踪反复重置隐藏计时。短说明真实进入仍可隐藏，但旧浮层位置的迟到事件不得隐藏当前源说明；抽奖也增加实际光标位置校验。
- 本轮不修改商品、库存、技能、属性与交易请求。game/content源文件与7份vjs编译产物配套。

## 验证

在实际存档生产脚本图、真实积分道具目录中新增测试：旧代码出现“停下后没有弹窗”，修复代码通过；包含100次往返切换、先新移入后旧移出、故意漏掉mouseover、原地停留、模拟网格滚动后当前道具变化、离开和关闭。循环中面板总数不增长。

Node `--test` 20份相关测试文件合计48项通过：共享dismiss和缩放映射、存档生命周期/碎片/品质/叠加物/字体、签到快速切换/迟到事件/月卡父子图标/重开、收藏补偿漏事件、商城整行快速切换50次和长说明、物品栏、HUD技能、研究、宝物原生弹窗、抽奖长短说明与重载。缩放映射覆盖Fit 0.5/1.4，商城覆盖native与CSS缩放。

历史抽奖测试曾要求回到真实源道具后仍不显示，与已有source rearm契约及本次连续悬停需求不符，本轮改为即时重开；补充实际浮层进入与迟到浮层事件的区别。商城旧负向fixture现在受到新的共享源优先保护，更新为验证该保护有效，原快速返回、旧来源owner和内部裁剪的负向检查保留。

7份修改后的Panorama JS通过Dota资源编译器；源码镜像、编译文件与测试日志位于工作目录和忽略目录 `output/tooltip_follow_20261028/`。完整资源编译与自动回归不替代实际Dota鼠标、分辨率与UI缩放验收，本轮未上传游廊或切换任何云端服务。

实机核对：重载界面/重新进入对局后，在积分道具首行左右快速往返并分别停下；滚动到中段后换物品；收藏、签到、商城、抽奖分别检查说明切换；长说明进入滚动条；关闭重开后再次悬停。应直接显示当前道具内容，不残留旧说明、不必额外移出移入。
