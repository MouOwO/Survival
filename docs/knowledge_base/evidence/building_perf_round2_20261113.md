## 已修复路径

1. `wall_melee_queue.lua` 的间距检测原来对每个候选遍历全部预留记录并开方。现在按128单位网格覆盖每个预留身体的包围盒，只访问候选周边网格；同一记录跨格去重，真正碰撞仍按原阈值精确判断。释放、死亡补位、实体ID复用和位置晋升同步维护索引，空格立即删除，城墙搬迁/重置释放旧队列。
2. `wall_melee_contact.lua` 的范围、到位与身体间距阈值改为距离平方；严格/非严格边界分别保留。实际导航长度、归一化、`距离+容差` 等运算仍保留必要开方，不能把它们直接替换为平方。
3. `worker_system.lua` 的树枯竭事件直接按攻击者 entindex 获取已有工人索引，并核对对象身份，替代全工人查找。
4. 血条客户端维护存活键与位置索引，收到死亡/移除包立即释放面板和引用。全屏遮挡只在进入遮挡时隐藏一次；新的面板默认隐藏。移动单位和镜头的存活血条仍逐帧投影，保持原有跟随效果。
5. 金矿只读取永久奖励中所需的5个字段，避免每次产出和重排任务复制完整权益、显示快照及聚合无关玩家。读取仍来自当次权威数据，不引入过期缓存；收入、暴击、分数累积与间隔算法未改。
6. 原生Tools发现轨道炮回调 `GetIntellect()` 缺少当前绑定要求的布尔参数，会使回调失败。改为 `GetIntellect(false)`，同时复用已有护甲字段查询，保持原伤害、目标、持续时间与先前移除占位塔的结果。
