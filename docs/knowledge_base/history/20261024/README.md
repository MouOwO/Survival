# 孤城逐晓／Survival 项目知识包

整理日期：2026-10-24。用途：让新会话或新项目快速理解核心玩法、数据契约、平台接入和已经踩过的技术问题。这里保存的是经过压缩的知识和证据索引，不是完整源码、游戏客户端、数据库备份或部署凭据。

**先读 [00_START_HERE.md](00_START_HERE.md)，再按任务打开一个领域模块。** 不需要每次读取全部历史。机器可读入口为 [data/context.json](data/context.json)。

`data/` 保存领域事实、来源哈希、会话覆盖和两仓状态；`evidence/` 保存经过字段筛选的公开发布摘要。源码路径以原 game 仓库为基准，content 路径会单独注明；文中简写 `core/`、`systems/`、`config/` 位于 `scripts/vscripts/`，`payment_backend/` 位于 `server/`。来源文件本身未全部复制，未来实施仍应读取对应版本代码和迁移。

阅读时分清三层：**当前开发代码、已经发布的签名冻结包、历史文档/需求**。当前开发有全难度只读验收开关；线上 v05 已实证的是原游廊单人授权、读档、N5 游戏与云端检查点，不代表多人托管和支付上线。

精简策略：保留玩法公式和权威源、事务/身份/并发边界、关键故障及有效修复；删去摘要里的重复截图、CSS 尺寸、图标排版和临时排查往返。UI 涉及账号、购买、奖励或门禁的业务契约仍保留。原始 Codex 会话、仓库旧文档和游戏资源未被这次整理删除或重写。

文件格式为 UTF-8 Markdown（`.md`）与 JSON；MD5 只用于兼容校验，并非文档格式或安全签名。完整性清单为 `MD5SUMS.md5` 和 `SHA256SUMS.txt`，优先核对 SHA256；实际游戏发行继续沿用其 Ed25519 信任策略。可运行 `python tools/verify_bundle.py` 检查本知识包，不修改任何文件。清单不包含自身，避免循环摘要。

知识包没有携带密钥、密码、Cookie、Bearer、完整 OpenID 回调、支付证书、订单明细或玩家数据。本项目历史授权不转移到新项目；部署、收费、公开发布和第三方接入仍按新任务的实际授权执行。发现资料与当前源码不符时，先核对证据并更新对应模块，不以历史聊天覆盖当前事实。
