可以复用的是契约和经验证的方法：身份与玩家归属、永久档/本局投影分离、请求版本和过期回包拒绝、不可变商品订单、支付验签与事务幂等发放、冻结签名资源、源码与编译证明、真实多账号分层验收、清晰的知识交接。

必须重新配置并审查：Workshop/App ID、Steam登录回调与域名、测试白名单、账号命名空间、数据库与角色、签名信任根、支付商户与证书、服务端网络、编译工具、资源许可、部署权限和发布范围。不要复制现有私钥、数据文件、玩家档案、浏览器会话或付款链接。

原游廊平台的HTTP/地图换图实现是本项目实际观察得到的路径，不是通用Valve规则。当前server-only changelevel保留完整自定义游戏上下文和真实名单已在本项目验证；新地图/新客户端版本必须重新测试。网站不能替代Dota实例，第三方VG/散夜托管及商业合作没有取得确定可交付合同。

新项目最小验证顺序：先单机加载与业务逻辑，再真实两个账号同局/重连，再网页登录与独立档，再无付款扫码识别，再小额实付和权益读取，最后长局、冲突、退款和更多玩家。每一项只记录实际结果，不以单测/单人成功推断商业上线就绪。
