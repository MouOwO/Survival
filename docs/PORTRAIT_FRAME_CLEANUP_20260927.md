# 头像横线、状态脸谱与背景修正

前一次修复解决了 Doom 头像属性同步引起的反复重建，但没有处理原生头像的兄弟覆盖层，因此不等于解决所有横线问题。

从本机 Valve HUD 实际布局和样式确认：`RightSideHeroBlur` 是 `src="panel://portraitHUD"` 的副本，保留 175×175 和负偏移；当前头像已调整至 264×264，副本边缘会留在头像内部。`SilenceIcon` 和 `MutedIcon` 是原生沉默与禁用物品提示，罪渊待挑战限制会持续触发。原生 `portraitHUDOverlay`、旧 HUD 装饰与检查按钮也独立于动态模型。

新增 `portrait_presentation.js`，在正常 HUD 刷新中隐藏这些独立覆盖层，并在引擎重建节点或重写状态后重新应用。原生/自定义 3D 主窗口的显示权、多选区域、自定义金框、等级牌和实际战斗限制保持不变，无新增定时器。

背景更换为与深蓝青色 HUD 匹配的柔和渐层，使用新材质路径 `materials/survival_ui/portrait_hud_backdrop.vmat`，同时在实际头像容器设置匹配底色。清空头像背景模型、地图与粒子项，并禁用投影。全体 1048 份头像配置使用同一背景，镜头和灯光参数不变。

已同步 content 并编译 game 资源，验证实际材质引用 512×512 新纹理。4 项回归通过：覆盖层清理及重建、连续属性同步、多选、HUD 回调生命周期。详情见 `docs/ai/validation/20260927/portrait_frame_cleanup.json`。

尚未进行实机渲染验收。完整退出并重新启动 Dota 2 后，新开对局检查：Doom 头像中段横线；十宗罪待挑战头像脸谱；英雄、怪物、建筑、伐木工的背景；连续切换与多选恢复。
