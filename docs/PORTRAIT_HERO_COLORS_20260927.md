# 根据头像模型主色切换背景（2026-09-27）

用户要求参考 Dota 2 原版，根据头像英雄的主色填充底色，如灰烬之灵金色、拉比克阴暗绿色。

## 实现

- tools/build_portrait_palette.py 读取本机 pak01_dir.vpk 中的 portraits.txt 和各英雄独立配置，映射英雄模型、项目 asset_catalog 与单位别名。彩色参数沿用原版色相并压低亮度；白色乘色参数背后的彩色纹理使用人工配置的主题色。灰烬、拉比克和六个可选英雄明确配置。
- 生成 portrait_palette.js：128 个英雄、194 个项目资源、271 个单位别名。背景按实际 portrait_unit_name、model_asset_id、当前原生单位名依次解析。
- portrait_presentation.js 将对应颜色用于实际可见的 PortraitContainer 与自定义 ScenePanel 外层，去掉遮住底色的统一 slate PNG，使用同色系由亮到暗的渐变。保留模型动画、摄像机和金边，不给人物本身染色。
- combat_stats.js 在接收合法当前单位快照时传递身份，颜色解析严格验证 entity，避免快速切换单位时用到上一单位的主题。
- 普通建筑使用与当前青灰建筑主体匹配的低饱和底色；借用英雄头像的塔/怪物使用对应英雄色。

## 验证与限制

头像清理、3 秒状态图标、角色主色、模型覆盖、跨单位旧快照防串色、原生/自定义背景一致性测试通过；战斗快照回调、多选、七宗罪相关测试通过。界面完整编译 13 成功、0 失败，最终配色表单独编译成功。
