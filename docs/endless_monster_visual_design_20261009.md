# 无尽挑战怪物外观循环设计（2026-10-09）

状态：已完成设计表与本机资源核对，尚未接入游戏。先看[Excel总表](design/endless_monster_visual_design_20261009.xlsx)，其中包含50怪总表、1000波展开和完整资源清单。

同一波所有怪物保持相同外观。前50波每波使用一个不同的非人形主体；后续每50波重复这些怪物身份并换一套饰品。每200波重复一次模型与饰品组合。按用户确认，第201波起固定为各自基础尺寸的1.5倍，之后不累乘。

选用狼兽、蛛虫、蛙兽、雷蜥、飞龙、猛禽、巨蝎、异虫、巨兽等。部分属于同一族群的不同正式模型，50个模型并不等于50种生物。用交错排列减少连续多波长得相似，后段逐渐出现更大型的怪物形态；这些安排只影响外观，数值仍读原波次配置。

总表同一行的四列对应四次循环。例如第1、51、101、151波都是灰鬃狼，分别为原生、双骨角、肩背晶簇、棘刺背冠与额心宝石；第201波重复第1波，但体型为1.5倍，第401波仍为1.5倍。第50、100、150、200波都是肉山异兽，第250波重复第50波并放大1.5倍。

通用饰物使用的真实资源如下。名称是本项目的设计用途，不代表官方套装名称；各怪物的挂点、缩放与转向仍需要实机校准。

| 饰物 | 用途 | 本机模型资源 |
| --- | --- | --- |
| bone_point | 短骨角、骨钉；单体可缩放与转向 | `models/props_bones/bone001.vmdl` |
| bone_rib | 背部骨甲、骨护胸；仅做小比例装饰 | `models/props_bones/bones_ribcage001.vmdl` |
| crystal_cluster | 肩背晶簇、头部晶冠 | `models/props_rock/crystal_01.vmdl` |
| crystal_thorn | 棘冠、晶体背脊；与晶簇形成几何区别 | `models/props_destruction/crystal_spike.vmdl` |
| centered_gem | 额心或胸部小型核心宝石；不附带神杖功能 | `models/props_gameplay/aghanim_gem_centered.vmdl` |

接入步骤：每波开始时只计算一次怪物序号与饰品轮次，整波复用同一套定义；出生时装配，死亡／结束时清理。序号为`(波次−1)%50+1`，饰品轮次为`floor((波次−1)/50)%4+1`，尺寸倍率为`波次≤200 ? 1 : 1.5`。没有每帧换装或搜索。

现有无尽生成服务直接读取规则表里的固定影魔模型，这是当前所有怪共用一套外观的原因。后续需新增独立视觉循环配置，再把解析结果传入现有挑战生成入口。原生套装走`default_wearable_asset_id`并补全预载；通用饰物需补纯父跟随挂接分支，现有装配服务强制骨架合并，不能将不同骨架的晶体或骨片直接装上。

自定义路线每只最多两件小饰物，默认不加常驻粒子；原生套装也默认关闭环境粒子，确认小型粒子合适后最多保留一个。装配只执行一次，纯父跟随后随单位移动，无定时定位。饰物不参与碰撞。模型及饰物一并放大，保持原逻辑碰撞体；飞行外观也不改变现有地面移动与攻击判定。

已静态检查50个唯一主体的资源、依赖，以及站立、移动、攻击动画声明；尚未完成游戏内外观与穿戴目测。基础尺寸为包围盒估算的初始建议，正式接入后还要从游戏镜头校正。当前战斗属性已配置1000波，本设计完整展开至1000波；超过1000波仍需独立配置战斗属性，不能仅凭外观循环增加波数。
