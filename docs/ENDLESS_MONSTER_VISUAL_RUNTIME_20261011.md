每波开始解析一次并缓存外观；出生时装配一次，移动依靠骨架或父挂点跟随。11种怪物英雄使用真实完整原生部件，39种其他怪物使用原生主体及后续小型骨饰、晶体饰物。自定义每只最多两件，无常驻粒子，也没有每帧定位。自然死亡保留装配到尸体沉降结束；取消、超时、失败或装配异常会清理所有所属饰物。

预载枚举209个直接模型入口，其递归依赖共1811项，在本机官方资源包中未发现缺失。使用已有已编译原生资源，无须新增模型或粒子编译。当前数值表、每波数量、出生间隔、60秒期限、评分、地面移动、攻击射程与逻辑碰撞均沿用原配置；外观尺寸不改变碰撞半径。

真实生产配置、工厂、数值投影、装配与尸体服务的受控回归覆盖401波，55472项检查通过；开局预载包含后续饰品，并验证新资源加载失败时不会错误放行。尚未取得真实游戏镜头目测，重点检查饰物贴合、部件缩放和移动／攻击动画观感。
