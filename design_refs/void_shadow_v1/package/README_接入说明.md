# 虚空之影组件包 V1

本包仅整理虚空之影。布局保持 8＋8＋7，单元只有方形图标、右上数量、下方名称。其余分类保留外壳标签，不制作内部内容。

## 文件用途

| 文件或目录 | 用途 |
| --- | --- |
| previews/reassembled_dynamic.png | 实际读取 assets 与 layout.json 拼装的动态文字版，供本轮审阅 |
| previews/reassembled_reference.png | 实际读取原图切片拼回的对照图；原分辨率像素差异为 0 |
| assets/backgrounds | 顶栏、资源条、侧栏、内容区无字底板；scene_exterior_reference 仅供预览，游戏使用实时场景 |
| assets/common | 边框、选中条、筛选底、数量牌、叉号和资源图标 |
| assets/items | 23 个同源物品图标，保留可见画面；旧数量板遮住的区域为透明缺口 |
| layout.json | 导出素材名、尺寸、坐标、叠放顺序、散列及文本样式 |
| data_preview.json | 预览内容；接入时必须读取项目真实配置，不覆盖存档数据 |
| reference | 原图切片与坐标审计，只用于像素验收；带字切片不得用于正式动态 UI |
| fonts | 思源黑体与许可证，名称和数字采用同一字体 |
| QA.json | 原图像素核验、素材数量、范围等结果 |
| reassemble.py / check_reference.py | 可复现两种组装；Python 3 与 Pillow 即可运行 |

**两种预览不能混为一谈。** 参考切片的零差异不代表动态文字版逐像素一致。动态版背景是同源空白纹理补底，不是恢复 PSD 原生图层；数量牌是按原图颜色重建的无字公共板，字体为真实思源黑体。因此文字笔画和少量底纹会与原图不同。

## 关键尺寸和复用规则

母图坐标系为 **1672×941**，左上原点，bbox 右下不包含。PNG 自带尺寸就是导出尺寸；不要将坐标直接当成 1920×1080 使用。

| 部分 | 母图坐标 / 尺寸 |
| --- | --- |
| 主区域外框 | [133,11,1536,903] |
| 左侧栏 | [136,128,394,897]，258×769 |
| 内容区 | [394,128,1533,897]，1139×769 |
| 物品布局 | 8＋8＋7；列间距约138px，行间距约193px，以每项 bbox 为准 |
| 图标 | 保留原裁切尺寸，约117–119×120–122；不拉伸主体，图标画面本身是方形底 |
| 公共数量牌 | 86×32，九切片边距4；各项宽度由quantity_bbox指定 |
| 公共筛选底 | 默认131×43、选中132×43，文字另叠加 |
| 左侧选中条 | 258×51，金色边线与整条底板同源；不新增大卡片 |

按逻辑分辨率整体等比适配：`s = min(视口宽/1672, 视口高/941)`，统一缩放同一父容器，并居中。不要独立拉伸背景、改变图标比例，或分别给数量与图标套不同缩放。背景在游戏中使用实时场景；本包的外部场景图仅展示构图。

物品单元由独立 Image、数量背景 Image、数量 Label、名称 Label 组成。所有单元复用同一数量牌和文本规则，不为每件物品另造卡片。数量牌保持固定右侧锚点；缩小、移走或隐藏它会露出被旧角标遮挡的图标缺口。增大宽度时向左延伸，仍须完全覆盖 `occluded_local_bbox`；不能声称被遮住的图案已恢复。

本轮只有当前截图可核实的默认/选中公共样式，没有另造按钮的禁用、悬停、按下图。关闭叉号为独立无框素材。

## 内容与行为

- `current > 0` 为已拥有，`current == 0` 才未解锁；未知值 `null` /「—」不得当成0。
- 分母是持有上限，不是解锁目标。没有上限数据只显示数量，不补统一分母。
- 23 是此截图的可见条目数量，不是分类容量上限。正式名称、数量、上限来自项目配置。
-「弦类道具」「能类道具」是待核对的占位名；虚空护罩、相位之力的当前数量未核实。
- 道具效果和条件保留在 Tooltip；常驻界面不增加说明、大卡片、进度条、购买或升级按钮。
- 此包尚未导入游戏，不能把离线预览验收当作 Panorama 的实际验收。

## 复现与验收

```sh
python reassemble.py
python check_reference.py
```

动态预览仅读取本包的 PNG、字体与 JSON，不读取母图。对齐版仅读取 reference 的切片。改动 assets 后重新运行，并核对图标主体、固定角标遮挡关系、文本不越界、底板衔接。正式接入还需验证0、无分母、未知数量、多位数字及长名称；数量多位时扩大数量牌或缩字，名称超宽时省略并在 Tooltip 显示完整名称。
