# 第8轮组件尺寸与组装说明

本参考包已整合完整素材与字体，不需要再叠加第6/7轮压缩包。本文件记录第8轮的布局与组件用法。

## 本轮验收重点

- 顶部山水与内容面板：移除原水平金色硬线，增加透明云雾渐淡过渡。
- 侧栏与内容面板：细边加窄幅雾化，保留明确的布局分区。
- 商品卡片：哑光象牙细纹、浅青玉边缘、细微内侧高光和下缘阴影。
- 物品展示：透明原物品图配独立阴影层、淡展示环和落地软影。
- 商品名称与价格：沿用可替换文本；细分隔线和弱内凹信息底，不能做成可点击价格按钮。
- 悬停：沿用金边、微上移、购买按钮；遮罩四边渐淡，取消原独立的深色描述条。

## 布局与独立组件

设计坐标是1920×1080；窗口1600×920，位于(160,80)。坐标以窗口或商品单元左上角为原点，按layout.json执行。不能对贴图逐张使用不同缩放比例。

## 给实现AI的说明

只调整商城视觉，复用既有导航、窗口、货币图标、文本节点和商品数据。保留点击与购买流程，不新增商品详情页，不改价格、效果描述或支付接口。

先合并累计补丁，再根据layout.json与本表叠放各层：卡片阴影→卡片底→展示底/云纹→物品阴影→透明物品图→悬停遮罩→动态描述/购买按钮；名称与价格始终单独显示。所有纯装饰层禁止接收鼠标事件。

source/shop.html是组件预览，不是可直接放入Dota 2的Panorama页面。按项目原有XML/CSS/JS节点结构实现坐标和层级。不要直接照搬浏览器CSS滤镜；物品投影已经导出成独立PNG。亮度/饱和度等浏览器预览滤镜只是轻微调色，游戏渲染不支持时保留原素材颜色，优先验证游戏截图。已有商品真实素材如果不是透明图，需先准备其对应透明素材和独立阴影，不能拿当前8张示例物品覆盖全部商品。

以previews/shop_v8_normal.png和shop_v8_hover.png验收。图片层、文本、hover层必须使用实际组件拼装，不能用整张预览贴图冒充接入。

## 可复现源文件

source/materials/*.svg：本轮确定性材质源；build_materials.py修改并生成这些SVG。source/build.mjs导出组件PNG与物品阴影；source/render.mjs渲染实际组装并检查；source/preview_compare.mjs生成前后对比。

preview_qa.json记录本地Chromium检查结果：资源、字体、悬停、文字边界、装饰层点击穿透、选中底线对齐，以及1280×720、2560×1440、2560×1080三个窗口范围。尚未进行游戏内验证。
