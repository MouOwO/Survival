# 存档 UI 最终组件包

用户已确认 V10 为最终视觉基准。本包汇总这一版实际使用的组件、字体、布局与正常/悬停组装预览，独立使用，不需要另找之前的增量包。尚未代用户导入游戏。

## 给实现 AI 的入口

先读《AI接入任务.txt》，再读 layout.json、asset_manifest.json 和《分类与切换契约.json》。以 previews/page_normal.png 为视觉基准，previews/page_hover.png 为悬停及 Tooltip 基准。根目录 render_preview.py 可用 Pillow 在本包内复现效果，不依赖旧版本文件夹。

## 用户确认的结构

整个存档只有一套共用外壳。顶部导航、左侧分类、背景、资源栏位置、关闭叉号、上下暗金横轨均固定。点击任意左侧 Toggle，只切换右侧内容并更新该 Toggle 的选中态；分类切换不使外壳跳动或重新加载整张界面。

右侧沿用本版网格与单元尺寸，单元主要是图标、图内右上角独立数字和下方名称。不同类别通过数据和文本说明区分持有数量、累计条件、目标门槛、等级与激活状态，效果和条件放 Tooltip。分类原有必要的升级、抽奖入口及专属资源在右侧保留，沿用项目已有行为，不新增未确认业务。

V10共用视觉与虚空之影页面已确认；其他分类的真实内容从游戏项目读取，本包没有凭截图补齐其全部正式数据。data_preview.json 与 tooltip_preview_data.json 仅用于复现，不写回生产配置。23项与8+8+7是当前预览，不是全部分类总数限制。

## 最终外观

干净连续紫色星云，半透明深色左栏，文字靠右，左栏选中为克制的暖色渐变。取消窗口外侧竖框，上横线收齐不出头；上下暗金同色，中间略亮、两端略暗；下角钩向下弯，有曲线亮面、暗面和厚度。数量没有底板，图标有细边，悬停有暖金边；Tooltip复用一套视觉。

## 资源与适配

assets/ 内是实际组件；asset_manifest.json 记录来源、尺寸、路径、用途与校验信息。字体与许可见 fonts/。assets/preview_only 中的外部游戏画面仅用于对照，不能作为运行时背景覆盖实际地图。

1672×941是参考画布，位置以 layout.json 为准。游戏由同一父容器管理缩放与锚点，端钩保持比例，横线中段可延展，受光中心要随容器映射。长列表仅在右侧滚动，数量/名称/余额/Tooltip均为独立文本，不能做成整页图片。

验收要包含全部左侧分类的切换、真实数据与原有入口、多分辨率和长列表。能运行游戏时提供实际截图；离线组装与游戏运行验收分开记录。
