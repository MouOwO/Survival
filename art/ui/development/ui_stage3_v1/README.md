## 具体改动

### 肉鸽大图

- 按真实 ID、名称与效果生成52张独立插画，1024×1536 RGBA，真实 Alpha；原48启用、4停用保持不变。
- 源图：`panorama/src/images/custom_game/rogue_cards_v1/<card_id>.png`。
- 新表 `rogue_reward_art.csv` 记录 ID、名称、路径及232×348设计展示区。构建使用审计后的对应映射；更换图片须重新审计/构建，不是改表就自动更新已编译客户端。
- `art/prompts.json` 保留生成依据，`art/audit.json` 保留尺寸/Alpha/哈希；生成52个 BGRA8888、带 mip 的运行纹理。文字与数值不烘焙进图。
- 沿用入场650ms、错开110ms、等待100ms、翻面540ms；悬停160ms、1.035倍、上移4设计像素。抽奖动画与肉鸽动画分开。
- 修正图片原尺寸显示造成的卡框裁切。外框和插画区域正常，但内拱形装饰空白修补仍有接缝，不能称逐像素还原。

### HUD / 生命周期

- 图标下方独立显示返回、设置、宝物、存档、装备、抽奖、福利、外观、社交；保留原事件，顶部 Tooltip 仍关闭。
- geometry.js 固定原四技能布局的人物左上锚点；技能和血蓝共同扩展，空间不足时整体等比缩放。物品/技能格同尺寸正方形。极宽布局缩小时人物尺寸也缩小，不做分别拉伸。
- 每日首次加载、8秒超时重试、重复请求门禁；关闭停止视图轮询、重开恢复；原领取函数不变。
- 肉鸽重载清理旧控制器，销毁取消调度及事件/网络表监听，原选择提交不变。
- 肉鸽状态文字和减少动态效果入口移至卡牌上方，避免与扩展后的 HUD 重叠。
- 尝试过公共复选框流布局调整，实机未解决图形缺失，已撤回。最终 ui_components.js 与本轮前备份一致，未留下未经证实的全局修改。
