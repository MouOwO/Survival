# 当前 UI 开发文件

已删除早期存档、抽奖、HUD 试稿、旧版候选资源及已完成修复的实验目录。正式运行资源位于 `panorama`，当前发布说明见 `../tools/ui_release/README.md`。

保留目录及用途：

- `remaining_ui_handoff_v1`：当前综合构建源码、基线、候选结果和交互测试。
- `shop_preview_v1`：当前商城模拟流程源码及测试。
- `ui_stage3_v1`：当前 HUD 布局逻辑、肉鸽插画映射和测试。
- `archive_polish_v1`：当前构建引用的九宫格公共实现。
- `ui_handoff_v1`：确认版交接包及仍被录制工具引用的窗口定位脚本；早期构建、候选和基线已移除。
- `ui_reuse_import`：公共组件源、资源注册表及相关构建输入。
- `font_import`：字体原始文件、授权说明和导入工具；旧探针字体副本已移除。
- `daily_rewards_import`：当前每日奖励测试所需 fixture 及相关导入数据。
- `player_hosted_feasibility`：非 UI 的可行性研究资料，本轮未按废弃 UI 删除。

本轮逐文件清理记录见 `../tools/ui_release/LEGACY_PRUNE.md`。旧阶段文档中的已清理文件链接仅作历史记录，按备份清单查找，不代表当前依赖。
