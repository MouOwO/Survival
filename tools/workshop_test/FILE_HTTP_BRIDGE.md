# 封闭测试临时 HTTPS 传输助手

此工具只负责传输，不授予登录资格。游戏仍从原正式游廊进入；真实 Steam 网页授权、
后台账号/会话校验、云档案及原交易校验保持。当前仅支持原五账号、普通客户端本机
承载的 template_map；Tools、开发配置、官方专服及其他地图不启用。
原生 HTTP 成功时优先使用原生对象，两个工厂均创建失败才尝试此适配层。

## 使用边界

先启动普通 Dota 并停在主菜单，确认该进程的 PID、创建 FILETIME 和安装路径，
再运行助手，看到 ready 后进入原游戏。开发机入口为：

```powershell
python -B tools/workshop_test/file_http_bridge.py --game-root '<Dota安装目录>/game' --pid <PID> --filetime <FILETIME> --state-dir '<树外全新运行目录>' --apply
```

不带 --apply 仅检查参数，不创建文件或发送请求。不要在已有授权会话中途重启助手；
真实设备凭据和访问令牌只在助手内存中保存，退出后失效的代号需要重新授权。
PID复用、路径不符、已有未知桥接文件均拒绝继续。异常断电遗留文件须先核对所属
进程已经退出和实际回执，再按精确文件清单恢复，不能批量删除 cfg 目录。

不开放本机端口，不改引擎或注入进程，不提供任意控制台命令、URL、Lua执行或重试
业务写入能力。只连接固定 HTTPS 后台及代码中列明的现有业务路由，禁止重定向。
TLS使用系统/Python信任链，拒绝跳过证书验证。

真实 device_code、access_token 被替换为内存代号；访问代号仍满足原 pwa1_ 格式，
但只能由本助手按账号/会话还原。它不是额外登录证明。nonce仅关联文件传输，
不是玩家身份、签名或后台授权。封闭测试验证不代表公共发行安全验收。

助手保护 console.log 和生成 cfg 的 DACL，仅允许当前用户及 SYSTEM。日志可能
包含私有业务负载，因此退出后仍保持私有；原日志DACL二进制及文件身份保存在
指定私有运行目录。生成的固定 bootstrap/cursor、分块文件退出时仅在摘要相符
时删除，其他文件不删除。助手退出、超时、换局、重复/错误回包均不能放行游戏。

## 成本与验证

Lua初始化一次核对五账号配置并注册四命令，稳定空闲无Think、无exec、无HTTP。
每次成功握手后预置下局的新随机nonce，重复ready不重置请求序号；跨VM编号重用
也不会接收上一局回包。初始化仅一次小文件原子写入，无定时目录扫描。
活动等待每0.2秒读取一个小cursor；每Think最多两个1KiB请求块或一个最多16×192
字节的回复块。按请求ID关联，截止时间使用索引堆，N≤16，取消/过期O(log N)，
字节编解码O(B)，不扫描玩家/场景/全量待办。辅助程序增量跟随日志，每次读≤64KiB，
空闲每0.05秒检查进程和新增字节，四个工作线程、最多16未完成任务；完成通知入队，
截止堆按ID删除，不逐轮扫描Future或请求集合。响应上限8MiB，但大响应仍须在原
业务截止时间内完成；不能将字节上限当作30秒可传输保证。未以这些计数代替FPS实测。

无网络回归：test_file_http_bridge.py、scripts/vscripts/tests/test_file_http_bridge.lua。
必须另做真实普通客户端、正式签包和官方下载验证，不能以Mock代替授权、读档、保存
验收。不得自动发起真实购买、用券、兑奖、清档。
