# 封闭测试临时 HTTPS 传输助手（协议2）

游戏仍从原正式游廊进入；助手只传输，不授予登录资格。真实Steam网页授权、后台
账号/会话、云档案和原交易检查保持。只支持原五账号、非Tools、非专服的template_map。
原生HTTP对象成功时优先使用，两个工厂创建失败后才采用助手。

先启动普通Dota并停在主菜单，核实PID和创建FILETIME，然后运行：

```powershell
python -B tools/workshop_test/file_http_bridge.py --game-root '<Dota安装目录>/game' --pid <PID> --filetime <FILETIME> --state-dir '<树外全新运行目录>' --apply
```

看到ready后进入原游廊游戏。不带--apply不创建文件或发HTTP。禁止中途重启助手后
继续使用旧授权代号；真实设备凭据/访问令牌仅在内存，丢失后须重新授权。
助手代码须与实际签名包的不可变Git来源一致。当前仓库版本不代表已发布版本。

## 原生KeyValues文件通道

协议1使用服务端exec读取cfg；本地匿名可用，但正式1901/1902未完成握手。
协议2改为LoadKeyValues读取固定cfg/*.txt，不执行控制台命令或注册远程命令。
游戏增量打印固定前缀描述符；助手增量跟随私有日志，向唯一固定HTTPS后台发送一次
请求，写入固定bootstrap/cursor与nonce/epoch/serial命名的分块KV文件。所有块写好后
才原子发布cursor；完成ack后删除自己拥有且摘要一致的文件。空闲不轮询游戏文件。
KV只写固定字段、数字、安全标记与带b前缀的base64，拒绝引号/换行/反斜杠等注入，
不写Lua/控制台指令。一次原生读取得到最多16×192字节原始数据的回复块。

每次握手消耗独立随机nonce并预置下局nonce，重复ready不重置最高请求ID，VM重用
epoch也不会接受旧回包。nonce只是关联标记，不是玩家身份、响应数字签名或登录证明。
设备码和pwa1_访问代号按账号/会话保存在助手内存，真实值不会写入IPC文件或游戏日志。
后台仍验证真实Steam授权，代号不能自行授权。封闭测试不能代替公共发行安全验收。

不开放端口、不修改引擎、不注入进程、不支持任意URL/重定向或自动重发业务写入。
TLS使用正常信任链，禁止跳过证书验证。只允许代码列出的现有业务路由和既定五账号。
PID复用/路径不符/未知遗留桥接文件均拒绝继续；不批量删除cfg或其他游戏文件。
助手保护生成文件和console.log的DACL，仅允许当前用户与SYSTEM。日志可能包含私有
业务负载，因此退出后保持私有；原DACL与文件身份保存到所指定树外私有运行目录。
异常断电遗留文件须先核对真实回执、进程已退出和精确所属文件，再恢复。

## 复杂度与验证

初始化O(5账号+64字符表)，每请求按ID插入索引截止堆O(log N)，N≤16；无玩家/场景扫描。
同步首步最多一次原生KV读，后续正延迟Think；无待办时Think/KV读/HTTP均0。
等候cursor最多5次读/秒；等候bootstrap最多一次/2秒。一次Think最多两个1KiB请求块
和一次KV文件读取；回复最多16×192字节/块，验证和拼接O(B)。截止删除O(log N)，
只处理实际变化/过期条目。每world一次started与仅超时的计数日志不含凭据。
助手每次增量读日志≤64KiB，空闲每0.05秒检查进程和新字节；四线程、最多16任务，
完成事件入队，不扫描Future/待办集合。响应上限8MiB，仍须遵守原业务截止时间；
不承诺所有8MiB响应都能在30秒传完。这些是预算/调用计数，不是FPS测量。
