# Survival 击杀时间计算器

直接打开 `index.html` 即可离线使用，不需要安装依赖或启动服务器。

输入当前面板物理攻击力与命中成长、暴击率与暴击伤害、多个攻击单位各自的每秒攻击次数，以及怪物War3显示护甲和生命值，即时得到离散命中下的期望伤害达标时间。

页面同时提供独立的“神秘路线录像实验”模式。该模式用于反推原版神秘之塔、魔能炮和魔能之眼的攻击时间线，不修改也不接入地图生产Lua或正式塔配置。

## 计算口径

- 第一次攻击在 `0` 秒命中，后续按 `1 / 每秒攻击次数` 的间隔命中。
- 可动态添加多个攻击单位。各单位使用独立攻击时间轴，但共享同一份全局当前攻击力。
- 每个普通攻击记录按暴击率独立随机判定，暴击伤害使用项目快照中的百分数。计算器使用 `1 + 暴击率 × (暴击倍率 - 1)` 作为每击期望倍率，不生成伪随机实战序列。
- 每次平A先按当前攻击力结算，之后才永久成长。同一时刻命中的所有单位共享成长前攻击力，结算后再按该时刻平A数量累计成长。
- 固定减甲视为先改变目标War3显示护甲；物理护甲无视再缩放剩余正护甲，零/负护甲不受百分比无视影响。
- 明确项目怪物的正护甲使用当前地图目标曲线 `1 / (1 + 0.02 × War3护甲)`。零/负护甲先按 `1/3` 投影为Dota运行时护甲，再使用当前项目的Dota护甲曲线。
- 击杀时间按完整攻击事件离散累计期望伤害，不使用 `生命值 / DPS` 近似。它不是随机暴击下某一局的保证值，也不是严格的随机停止时间数学期望。

## 数据来源

- `data/csv/公共规则/war3_damage_calculator_rules.csv`
- `data/csv/公共规则/war3_damage_calculator_mystery_experiment.csv`

修改 CSV 后，在项目根目录运行：

```powershell
pwsh -File tools/build_war3_damage_calculator.ps1
```

该命令会把项目怪物正护甲、War3到Dota投影和Dota护甲曲线常量同步进单文件 HTML 与生成 Lua，并把神秘路线实验预设仅嵌入单文件HTML。实验CSV不会生成Lua，也不会注册到`config/generated/index.lua`。

当前面板攻击力已经包含装备、研究、成长和英雄专属攻击乘区；不要在输入值上重复应用这些加成。计算器不包含最终伤害科技、Boss减伤、承伤光环、技能伤害、闪避、格挡、回血、攻击前摇和弹道飞行时间。

## 神秘路线录像实验口径

- 预设面板攻击力直接采用录像/工作簿值；不通过修改正式`tower_class_mystery.csv`补100。
- 原版默认时间线为`t=0`普通攻击、`t=1`激光首跳，之后两者各每秒一次。同刻普通攻击/激光顺序可切换，以观察击杀和叠层差异。
- 激光五级基础倍率为100%/120%/140%/160%/180%，每个有效Tick增加0.05，最高500%；切换主目标后从基础倍率重新成长。魔能炮与魔能之眼继续继承第五级180%。
- 魔能炮击杀层每层+10%，独立持续5秒，五级上限4/5/6/7/7。致死事件结束后才新增层，因此新层不会反向放大本次伤害。
- 魔能之眼只在普通攻击事件中，对塔与主目标线段路径内的其他单位造成30%物理伤害；主目标排除，路径单位按各自War3护甲独立结算。
- 路径半宽96只是旧实现近似值，页面允许调整，不代表已证明的原版权威值。
- 魔能炮层是否传递给魔能之眼仍无唯一录像证据，页面以默认关闭的显式实验开关保留两种模型。
- “立即首跳”仅用于比较后续改造；原版预设保持锁定后延迟1秒。0.5秒激光和目标周围150范围AOE不属于该原版默认模型。
