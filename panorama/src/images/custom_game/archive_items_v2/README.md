# 存档与商店独立图标

生成方式：内置 imagegen，每个真实条目单独生成。PNG 母图保留原始 RGBA 与 Alpha，没有裁出棋盘格、合成卡框或文字。当前工具输出为 1254×1254；存档图片区域沿用 93×74 设计像素并保持宽高比，商店、奖池使用各自现有图片区尺寸。

运行资源由 Source 2 原生纹理编译器从母图生成，不改母图像素。使用已在游戏中验证的 BGRA8888 格式：`archive_gpu_small/` 供存档小卡片使用，`archive_gpu_regular/` 供商店和奖励展示使用。编译目标分别为 64、256，当前编译器实际生成 66×66、313×313 的资源；以编译日志为准。DXT5 在当前 Panorama 图片入口显示异常，已排除。

运行映射：`data/csv/存档系统/archive_item_icons.csv`。同一真实物品在存档、抽奖奖励和商店中共用图片。映射只改视觉，不改 ID、数量、效果、价格、概率或领取条件。

分类设计：

- 积分、神兵、秘法牢笼、商店：依据真实名称设计独立的物品和武器。
- 好友、前女友：对应角色的 Q 版形象。孙悟空按《龙珠》、爱德华按《钢之炼金术师》、罗宾按《海贼王》、祈按楪祈处理；这些画面身份选择保存在提示词中，可逐项验收替换。两个唐三 ID 保留，后者采用海神形态作视觉区分。
- 瑞兽：当前表内名称为法宝，因此采用携带对应法宝的原创 Q 版神话生物；生物造型是美术设计，不作为新增游戏名称或属性。
- 角色审阅修正：美杜莎女王采用《斗破苍穹》彩鳞的人形；涂山雅雅采用黑发、红白服装、酒葫芦的经典造型。云界旗修正了旗杆顶端的画布裁切。修订提示词与先前母图保存在 `bulk_art/revisions/`，当前收录文件的来源由 `receipts/` 指向。
- 钓鱼：按真实鱼名的色彩和意象设计独立鱼形。
- 存档建筑：按表中的玲珑心、圣剑等实际装备名称作画，不套用早期建筑效果图中的房屋名称。

完整范围及生成提示词：`spikes/remaining_ui_handoff_v1/bulk_art/prompts.json`。
逐图来源记录：该目录的 `receipts/`。
资源审阅页：该目录的 `index.html`，明确区分资源审阅与游戏截图。

更新映射：运行 `tools/import_archive_art.py`，再运行 `tools/read_archive_icons.py` 验证真实条目、名称、尺寸和 Alpha。`tools/build_archive_art_review.py` 只制作审阅图，不改生产母图。

后续单独换图时修改表格中的 `icon_path`，重新构建及部署即可。批量登记工具只补充缺少的行，不覆盖已经手动调整的路径、启用状态、显示尺寸或验收状态。编译依赖清单不再重复编译完整分辨率的母图。

美术状态：`approved` 为之前用户认可的四张图；`generated_review` 为本批待验收图。不存在的资源不会写入启用映射，避免加载失败或用同一占位图冒充完成。

当前在 `survival_ui_handoff_v1` 隔离测试地图验证。存档右上角「图标试览」支持切分类和翻页，只读，不发放奖励。实际各分类仍遵循游戏持有/解锁显示规则。
